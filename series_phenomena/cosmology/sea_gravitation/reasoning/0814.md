# Reasoning — Patch 0814 (DM-2 Step 3: residual skew quantified)

STATUS: verbatim, at-patch (Opus, Session 156, 8 June 2026). DM-side; no verdict.

Step 3 was supposed to "nail the residual quantitatively," and it did — but it also caught me in a wrong-order assumption I had carried since 0809/0810, so the honest thing is to record the correction rather than smooth it over.

I had been treating the O(delta^3) NESS current as the channel that might (or, per 0810, might not) produce the bulk skew. Measuring the actual Mechanism-A NESS on the 600-cell shows the third central moment scales as O(delta^1), the same order as the tilt, while the current is O(delta^3) and subdominant. The reason is simple in hindsight: the rate bias (1 + delta e.nhat) breaks the enantiomorph (eta -> -eta) symmetry already at O(delta), so the measure is skewed at O(delta). 0810's "current is not skew" is still true, but I had the operative skew at the wrong order and from the wrong source. I flagged this as a correction in the doc; banking the wrong-order framing silently would have left a latent error in the arc.

The part I had to think hardest about: does an O(delta) skew reopen the cosmological-constant catastrophe? It would, if it produced a non-subtractable spatially-varying source. It does not, but NOT for the reason I would have liked (the skew is not small — it is O(delta), bigger than the current). It survives because Mechanism A's n^-bias is spatially uniform, so the induced skew is statistically homogeneous, so <F>_bulk is a uniform source — and a uniform source is exactly what gradient-control (0806) sends to zero curvature and what excess-sourcing (5c/D2) subtracts as ground state. The gravitating residual is the spatially-varying part = the IR-boundary horizon mode = Lambda (0807). So clean Lambda survives, but the load-bearing reason moved: it is now the homogeneity of the bias plus the D2 subtraction extended to a biased (skewed) ground state, not the smallness of any skew.

I was careful to state the residual risk this creates rather than claim victory: the biased-ground-state subtraction is a sharpening of D2, and it is exactly where a critic should push — if the covariantly-constant subtraction does not cleanly remove the homogeneous O(delta) skew term, there is an O(delta)*(gradient-variance) uniform residual to answer for. And the whole thing is still a single-walker proxy for the field skew (the scaling and homogeneity are robust to the lift; the coefficient is not). I would rather the arc carry that sharp open edge honestly than a tidy "clean Lambda, done."

Net: the residual is quantified (skew O(delta) homogeneous; current O(delta^3) subdominant); clean horizon-only Lambda survives conditional on the biased-ground-state subtraction; the 0809/0810 current-centric emphasis is corrected.
