# Reasoning — Patch 0851 (DM-1 §6 core-radius-vs-σ/m panel; NFW r₁ inversion)

Method: the standard SIDM r₁ inversion (Kaplinghat, Tulin & Yu 2016). The self-interaction thermalizes out to r₁ where ρ_NFW(r₁) = ρ₁(σ/m); the observable core radius ~ r₁. I parametrize each galaxy's NFW by (V_max [obs], c [model]) — ρ_s from c via the standard (200/3)ρ_crit c³/m(c), r_s from V_max via V_max² = 4πG ρ_s r_s²·0.2162 — then solve x(1+x)² = ρ_s/ρ₁ for r₁ = x·r_s with brentq. Velocity convention identical to 0850 in spirit but using the HALO dispersion σ_1D = V_max/√2 (the right scale for the halo-level r₁ method), tagged [conv].

What the computation actually returned, and the honest verdict it forced. I wrote the verdict AFTER running, from the numbers, not before:
