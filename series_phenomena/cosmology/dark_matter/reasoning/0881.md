## The physical shape (why N_dwarf = N_freeze)

The velocity dependence is asymmetric in a way that makes the dwarf size clean:

- **Dwarfs do not reprocess.** A dwarf collision deposits ~0.78 keV — below the bond window — so it
  neither fragments nor regrows the rod. The dwarf-resident rod keeps its **primordial freeze-out size**:
  **N_dwarf = N_freeze.**
- **Clusters reprocess.** A cluster collision deposits ~1.95 MeV > E_bond → fragments N_freeze → N_cluster
  → lower σ/m (collisionless). This is the velocity dependence (0878), now with N_dwarf identified.

So the whole question collapses to: *what is the primordial freeze-out size N_freeze?*

## N_freeze from reversible-aggregation freeze-out

For equal-K (isodesmic) linear self-assembly the number-average size is <N> = √(Kφ), with association
constant K = exp(E_bond/kT_form) and DM-element volume fraction φ. Hence

    N_freeze ~ √φ · exp(E_bond / 2 kT_form).

The **forward** map (E_bond/kT_form → N) is exponentially sensitive, so N is *not* absolutely predicted.
But the **inverse** map is benign: E_bond/kT_form = 2 ln(N/√φ) = 2 ln N − ln φ — only *logarithmic* in the
uncertain abundance φ. So the band-required N fixes the freeze-out ratio robustly.

  φ ~ 7×10⁻¹⁵ … 7×10⁻¹⁰.
- Band-required N_freeze ~ 5–60 (0878) ⇒ **E_bond/kT_form ~ 24–41** (robust; the 4-decade φ range only

- **Closure:** for kT_form ~ 1–19 keV this gives E_bond ~ 0.024–0.78 MeV — **inside the independently
  required fragmentation window [0.78 keV, 1.95 MeV]** at every point.
- **Velocity dependence** (N_freeze = 10, E_bond = 0.5 MeV): dwarf/group intact → σ/m ~ 1.1 (cores);
  cluster fragments → N ~ 2.6, σ/m ~ 0.28 (collisionless). The split is automatic and in the data-preferred
  direction.

## The result: an over-determined consistency (Layer C)

**Four independent constraints close on one point** — band magnitude (0878), reversible-aggregation
freeze-out, the fragmentation window (0860), and cluster-collisionless — at E_bond ~ 0.05–1 MeV,
kT_form ~ few–19 keV, N_dwarf ~ tens, with **no fine-tuning beyond E_bond/kT_form ~ 24–41**. This is the
swarm-countable advance: the same edge-bond depth that the 14-Gyr lifetime and the velocity split require
is the one that freezes the aggregate at the band-reaching size.

## Honest status and the falsifiable handle

- **Not yet a single number.** The forward exponential sensitivity means N is pinned to "tens" only as a
  *consistency*, not an absolute value.
- **Falsifiable:** SF-2/SF-5 pins E_bond and the relic/epoch calculation pins kT_form; if E_bond/kT_form
  falls outside ~24–41 the band is missed. **Pinning either one collapses N_dwarf to a single value and the
  core-size-vs-halo-mass relation to a definite curve** — the discriminating, swarm-countable prediction.
- **Caveats:** assumes isodesmic *equilibrium* freeze-out; a fully kinetic Smoluchowski-plus-Hubble
  treatment could shift the prefactor (not the logarithmic robustness). φ is inherited from the abundance
  (DM-1 §8 / Project C).
