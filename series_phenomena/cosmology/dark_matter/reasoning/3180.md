# Reasoning fragment — Patch 3180 (Phase 1B prereg + driver)

Three things had to be got right before this could be frozen.

1. SEED CONTINUITY. Extending N from 128 to 685 is only legitimate if
   the existing 128 legs remain valid members of the larger ensemble.
   numpy's Generator draws sequentially, so default_rng(31670817)
   .integers(1e6,1e7,size=685)[:128] is bit-identical to the size=128
   table — verified before freezing, and asserted in the driver at
   import so a future numpy change breaks loudly instead of silently
   re-seeding the campaign. Phase 1's beta=0.05 legs are reused
   byte-for-byte via leg_path_1b's pair<128 branch; nothing is recomputed.

2. THE FORBIDDEN SHORTCUT, RE-FORBIDDEN. The existing data would already
   resolve a ratio built on s(0.20)/s(0.10). That is exactly why it must
   not be computed: the endpoints were frozen before Phase 1 and the
   temptation is now stronger, not weaker, because we know which one
   works. The prereg names it forbidden and the driver never computes it.

3. THE COEFFICIENT READING IS SUSPENDED, NOT REPAIRED. Patch 3176 voided
   SUST_REF as a comparator (polarization amplitude transplanted into a
   force band, implied factor 1 vs computed <=0.008 or exactly 0). More
   data does not revive a void comparator, so --analyze-1b prints k as
   diagnostic arithmetic under a VOID label and fires no flag. The 3175
   coefficient finding stays retracted.

PRE-DECLARATION REVERSAL, recorded as a reversal: I expect BETA-LINEAR
this time. Phase 1's through-origin fit passed at k_hat = 7.37e-03
consistent with all four rungs and the upper three rose monotonically —
my Phase 1 expectation (FLAT/SUBLINEAR) was wrong, and carrying it
forward unchanged would be pretending otherwise. BETA-FLAT would now be
the surprise. Recording the reversal is the point: a worker who quietly
re-declares the expectation that the data already favours has not
pre-registered anything.

Scope honesty (prereg §5): with the comparator void, a BETA-LINEAR return
establishes an INSTRUMENT property — the response scales with drive — not
a physics verdict. Magnitude cannot be judged until OPEN-BAND-CONV-1
returns. The prereg forbids reporting it as more, because the pull to
present a clean scaling result as vindication will be strong.
