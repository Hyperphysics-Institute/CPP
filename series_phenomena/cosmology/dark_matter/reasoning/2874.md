The substantive event of the round is that my reconciliation is dead and

I need to be precise about what happened, because it would be easy to
narrate this as vindication of my caution and it is not quite that. I
built the finite-width/vanishing-first-moment story, I flagged it as the
fifth favourable convergence, and I asked for it to be attacked. It was
attacked and it did not survive. The argument that killed it is two lines
long: for a normalized nonnegative causal kernel, mu_1 = integral of
t K(t) dt is strictly positive, so chi(omega) carries a first-order term
in omega and there is nothing to cancel. Getting mu_1 = 0 at finite width
needs a signed or oscillatory kernel. I did not do that calculation. I
could have. I reached instead for a structural sentence — width and first
moment are independent — which is true as a general statement about
kernels and does nothing to establish that this kernel has the property.
That is the same failure mode as the gloss errors, in mathematical
costume: a characterisation standing in for a check.

S1's second point is the one I should have caught unaided. I moved from
the founder's fore/aft antisymmetry, which is spatial, to a vanishing
temporal first moment, in a single step, with nothing in between. Those
are different propositions about different integrals. I wrote the step
and did not see the gap.

Four seats ratified it. S3 called it standard in response theory, S4
wrote it as though it were definitional — width measure, moment measure,
therefore cancellation — which is not an argument, it is the claim
restated with arrows. That matters beyond this question. The panel's
majority is not evidence about a favourable convergence; it is a
measure of how plausible the convergence sounds, which is exactly the
property that makes it dangerous. One seat computed and the computation
went the other way.

Now the part I have to be careful about, because it is the sixth

So the structure S1 demands may already be sitting in the record.

I am not banking it and the reasons are specific rather than
