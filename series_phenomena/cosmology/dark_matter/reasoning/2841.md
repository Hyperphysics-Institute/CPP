# Reasoning fragment — Patch 2841 (a correction that narrows without rescuing)

**STATUS: verbatim, captured at patch. Session of 2026-07-27.**

## What the founder's correction actually revealed

He flagged that CPP has no instantaneous communication. My first
reaction was that this did not bear on the test, since the
electrodynamic pointing result is a theorem about a retarded theory,
not a claim of instantaneity — and that remains true and is recorded.
But following the thought further exposed something I had missed
entirely: the cancellation needs a current sector, my configuration
had a static jellium background, and C23 puts the magnetic field in
the Sea's arc response. There was no Sea in the run. I tested a scalar
retarded field and discovered that it behaves like a scalar retarded
field.

## The line I had to hold

This is a real scoping error and it would be easy to convert into a
reprieve: "the test was mis-scoped, so the withdrawal was premature,
so the Darwin bound stands." It does not follow. 2838's conditional
was that the relay reproduces the transverse sector; the relay
demonstrably does not, because C21 closes its content to charge,
polarity, and origin. Whether the SEA supplies it is a different and
currently untestable question. The bound stays withdrawn; only the
diagnosis changes.

Yesterday's fragment said a worker who uses a test's flaws to keep the
conclusion the test defeated has done the thing this campaign exists
to prevent. Today's flaw is mine and of a different kind, and the same
rule applies.

## The convergence worth noticing

1B's transverse component and PR4-COMPLETED's C23/C24 specification
have turned out to be the same gap approached from opposite sides:
both need a Sea that stores and returns arc structure. That is either
a sign the framework's open questions are fewer than they looked, or a
sign that one obstacle is load-bearing for more than we thought.
Either way it is worth the panel seeing, and it makes the first-order-
only closure route (items 2+3, no transverse confirmation) the
pragmatic path if they will accept a weaker bound.
