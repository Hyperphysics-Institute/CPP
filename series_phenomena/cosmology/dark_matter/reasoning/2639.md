# Reasoning — Patch 2639 (a conjunct that reads floating-point residue, and how to accuse an instrument politely)

STATUS: verbatim, at-patch.

The design work tonight was mostly one observation: the registered classifier's
CAP branch requires Sea > 0, and at η = 0 the sink is the split removed — Sea is
machine-zero by the 2621 C2 control's own measurement. A conjunct evaluated on
the sign of −1.4e−13 is a coin flip wearing a physics costume. The 2624 w=2 OFF
"patchwork UNR/CAP" has exactly the texture a coin-flip conjunct would produce:
cells that are physically bound flickering between CAP and UNR depending on
which side of zero the residue lands. So the hypothesis goes in the prereg
BEFORE the run, where a hypothesis belongs, and the instrument fix (drop the
sink-referential conjunct for sink-off cells) is preregistered with its own
conservatism control rather than applied quietly.

C-F2 is the accusation done politely. If the OFF-form classifier reproduces the
registered w=4 OFF bracket, the fix is conservative and the w=2 family reads
under it with a clean conscience. If it MOVES the registered bracket, then the
Sea-conjunct exposure reaches back into the 2624 record itself, and that goes
to the founder's packet as a flag, not into a silent re-reading. Either way the
side-by-side printout keeps both classifications in front of every OFF cell —
the record should never have to trust that I applied the right one.

The upper-bound family needed one honest scope sentence: the launcher's start
height is 4D no matter how large b gets, so at b = 16D the "funnel reach" is a
statement about the registered geometry's oblique approach, not about a
plane-wave flux. RF-UB-EXCEED therefore terminates the scan class rather than
inviting b = 32: a reach that beats 16D from a 4D launch height is a question
about the well's asymptotic form, and asymptotics are derived, not scanned.

The grids are deliberately coarse above 8D ({9,10,12,14,16}) because the object
being drawn is an upper BOUND, not a precision boundary — the bracket, wherever
it lands, can be refined later if any consumer ever needs it, and no consumer
tonight does.
