x_half = 28.0, Δ = +6, x_src0 = −24.0, L = 48.0" AND "T_END = 264 for
EVERY rung" AND "β ladder {0.10, 0.20, 0.40, 0.60}". These three freezes
are jointly over-determined: in the engine (2902, line 158) β is
prescribed source advection applied each Moment, so with the
corpus-standard protocol (drive on from T_STEP through T_END, the
semantics of every existing arm including a2 and AK) the path length is
L = β·(T_END − T_STEP) = 240β, which equals 48.0 only at β = 0.20. At
β = 0.10 the source cannot traverse 48 units within the frozen horizon at
all (it would need 480 driven Moments), so a drive-off-at-L=48 mechanism
cannot reconcile the freezes either — and it would be NEW instrument
mechanics, which the prereg nowhere introduces ("No new statistic is
introduced by this campaign"; the leg engine is the committed 3055
`run_leg`).

through T_END — and read the prereg's "L = 48.0, Δ = +6" line as the
description of the a2/AK configuration class being borrowed (it is
realized verbatim at the β = 0.20 rung). Consequence, disclosed rather
