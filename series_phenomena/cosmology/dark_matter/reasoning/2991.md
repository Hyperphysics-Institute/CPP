# Reasoning fragment — Patch 2991: three implementations, one reclassified anomaly

**The scope decision: three, not two.** The charter says "the two AUTOMATON relay
implementations" — written before the directed relay existed. Classifying only the literal two
would have omitted the one implementation that actually exhibits multi-Moment ballistic
transport (p = 1.0000), producing a record in which C-1 looks unevidenced when it is evidenced.
The charter's intent (classify the registered transport implementations against the mechanism
classes) beats its letter; the deviation is stated in the record's header, not smuggled.

**The reclassification is the patch's real content.** The 2887 finding — A-2's relay is
diffusive, no light cone — sat in the corpus as a worry against a RATIFIED result. Reading the
engine settles it: A-2's per-Moment kernel is exactly Version B's hop composition, but the
Moment-boundary re-aggregation deletes the origin address. Under the now-ratified P-1, the
address is the load-bearing steering content; delete it and synthesis v2 itself predicts
diffusion. So the diffusive measurement is not evidence against Version B — it is the negative
control that confirms the address is doing the work. The reclassification required no new
computation, only reading the code against the ratified ontology. A finding's meaning can
change when the ontology firms up beneath it; the anti-erasure way to handle that is a new
record citing both, never an edit of 2887.

**O-1 was unlooked-for.** Both engines aggregate DI-bit content into count fields and convolve
— valid only for count-like, phase-free content. Had the founder ruled YES on phase, every
AUTOMATON result would have needed re-derivation with complex amplitudes; the engines were
implicitly betting on AP-2 before it existed. Registering that as retroactive consistency
evidence (rather than silently enjoying the luck) is what makes the corpus auditable: the
dependency now runs both directions on the record.

**The proxy caveat on the directed relay earns its sentence.** Direction-persistence and
address-steering coincide at point-source straight-line geometry and NOWHERE else (multi-source,
scattering). Claiming the directed relay as a Version B engine simpliciter would plant a future
contradiction; claiming it as a C-1 front-class instrument at this geometry is exactly right.
Similarly A-1's inverse-square evidence is honest only as mechanism-class-SHARED — B and A agree
on the shell endpoint, so the ±2.9% cannot discriminate them, and pretending otherwise would
double-count evidence toward the adopted fork.

**What E-1 hands E-2.** Already evidenced: 1/r² counting (A-2), within-Moment N-hop
ballistics (A-2), multi-Moment ballistics (proxy). Outstanding: degree-6 residual, remainder
sensitivity, and — surfaced by O-2 — equalization/reservoir dynamics, untested by every
implementation because all impose conservation by construction. E-2's toy now has a precise
worklist instead of a scope sentence.
