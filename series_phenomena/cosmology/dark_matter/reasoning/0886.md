# 0886 — Element-level re-derivation: the cube-core element preserves ℓ_p and σ/m = 0.11·N

**Lane:** DM 08xx, DM-local. **Layer:** C→B (foundation hardened). DM-1 stays v0.1. No registry/swarm change.
**Trigger:** the open check flagged in the genesis footnote — and the prerequisite for the E_bond pin, since
that pin collapses N_dwarf → a single σ/m via σ/m = 0.11·N, whose normalization (hTetra-rung vs cube-element)
must be verified first.

## The question

0870 (stiffness) and 0878 (σ/m) were computed at the "hTetra-rung" abstraction. The adopted structure is the
cube-core element (8qCP + 8eCP = 4 hTetras; genesis 0880). Does "one N" mean one hTetra or one cube, and do
ℓ_p = c_geom·(E_bond/kT) and σ/m = 0.11·N survive at the element level?

## Findings

**(0) Mass.** m_element = 8 m_qCP + 8 m_eCP = 4·(2 m_qCP + 2 m_eCP) = **4 m_hTetra** (constituent count).

**(1) ℓ_p HOLDS; the "rung" was the cube-element all along.** 0870's stiffness is
ℓ_p = (E_bond/kT)·Σ_i(y_i − y_neutral)², Euler-Bernoulli for parallel coupled strands; the rung is the
**axial cross-section**, and Σ(dy_i)² = c_geom is the **width² lever** of whatever sits in that cross-section.
For the cube element the cross-section is the cube face (the four hTetra arms / 8 qCP) — a well-defined O(1)
geometry. So ℓ_p = c_geom·(E_bond/kT) holds with c_geom = the cube's width² lever. Crucially the four hTetras
sit in the **cross-section, not along the axis**, so one axial rung = one cube-element — which is what both
0870 (ℓ_p ~ 200–500) and 0878 (band-N ~ 5–60) counted. **Same units → the rigid-regime margin (band-N ≪ ℓ_p)
is intact**, not degraded by a factor of 4 as a naive "rung = hTetra" reading would have suggested.

**(2) σ/m = 0.11·N HOLDS with N = cube-elements; the 4× mass cancels.** The decisive input (f-derivation): the
residual color attraction is a **London/dispersion (polarizability)** force, ε ~ α²/a⁶ — not a permanent
multipole. Polarizability is **additive** in the colored constituents (α_cube ~ 4 α_hTetra), and so is mass,
so the 4× mass increase is **compensated by the constituent-count scaling of the cross-section**. Illustrative
vdW-length scaling (σ ~ R_vdW², R_vdW ~ (μC₆)^¼, C₆ ~ α²) gives σ/m per cube-element ~ (1–2)× the per-hTetra
floor — preserved up to an O(1) factor, possibly **mildly enhanced (~0.11 → ~0.2)**, well within the existing
g prefactor of σ/m = 0.11·N·g. **No factor-4 catastrophe.** (The eCP shell is electric: it screens the corona
channel, not the color residual, so σ/m is set by the unscreened cube core — consistent with the color floor.)

## Verdict and consequence

Both load-bearing results survive at the cube-element level; the cube-vs-rung ambiguity is removed (rung =
axial cross-section = cube-element), and the footnote's "open check" is **closed**. **The E_bond pin can build
on σ/m = 0.11·N (N = cube-elements) safely.** If the mild σ/m enhancement holds, the band-N shifts slightly
*down* (a few–tens of cube-elements) — still robustly rigid, still inside g; no qualitative change to any DM
result (the band is reached, velocity-dependent, corona retired). This hardens the foundation under the whole
quantitative chain (σ/m → N_dwarf → the E_bond pin) without moving any verdict.
