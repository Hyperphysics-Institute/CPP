I expected this analysis to dissolve the tension and it did the
opposite, which is worth savoring for a moment as evidence the
instruments are honest. Three seats and I all half-believed Gemini's
story — Metropolis chains notoriously underestimate errors, the
factor is 3 to 5, the 3-sigma evaporates. The windowed estimator says
no: sampling every fifth sweep of a 700-particle melee decorrelates
almost perfectly, tau under one sample everywhere, and the errors
were right the first time. So the discrepancy grew teeth: 4.1 sigma
with consistent chains is not noise.

And then the paradox, which I almost wrote past before the numbers
stopped me: the contact coupling is twice as strong at the CORE point
that AGREES than at the MAIN point that does not. Closure error that
improves as the closure is stressed harder is not closure error. The
window mismatch candidate came from staring at that inversion — the
two instruments never measured the same functional on the same
domain, and a profile carrying a genuine O(Gamma) shape deviation can
hand different windows different slopes with everyone computing
correctly. X6 was already chartered as a cross-check; tonight it
became the discriminator. If matched windows collapse the
discrepancy, the physics was in the shape all along; if they do not,
something real sits at a_s = 0.04 and the ladder will have to find
it. Either way PR1 stays honestly unmet, which is what a promotion
bar is for.
