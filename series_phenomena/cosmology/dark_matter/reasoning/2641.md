# Reasoning — Patch 2641 (the last instrumental attempt, declared as such before it runs)

STATUS: verbatim, at-patch.

The design content of this prereg is mostly one sentence: this is the LAST
union. The ROB-2 ladder set the precedent — one extra rung beyond the union
that failed, then the question routes to derivation — and the honest move is to
import that stopping rule here explicitly, before the run, while I don't yet
know whether the finer union will draw. If I wrote the prereg without the
stopping clause and the union failed, the temptation next session would be
{1/400, 1/800} and then {1/800, 1/1600}, each individually cheap, collectively
an instrument fitted to the wish. Freezing "no third union" tonight costs
nothing if the bracket draws and buys discipline if it doesn't.

The one genuinely new reading class is RF3-BRACKET-WITH-MARGIN-NOTE. The 2640
scan showed the steep boundary is marginal near b = 10; it is entirely possible
the finer union draws stable endpoints at, say, 9 and 12 while 10 stays
flippy. A rule that let an unstable interior cell veto stable endpoints would
confuse a bracket with a boundary curve — the registered object is "the reach
lies between these two b values," and interior marginality is information about
the boundary's shape, not about the bracket's validity. Pre-declaring that
distinction keeps the execution patch from having to invent it under the
pressure of a mixed table.

Everything else is deliberately nothing: same instrument, same grid, same
classifier (registered form — every cell is sink-ON, so the 2640 OFF-form
amendment never enters), one control that pins the shared leg to the fact 2640
already registered. The cell is small because the question is small; the only
thing that must not be small is the finality clause.
