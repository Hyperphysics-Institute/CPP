## The one thing 2426 rested on
2426's favorable make-or-break (κ_θ/E_bond = 2R²/d² ≈ 0.74–1.5, clears 0.43)
used the STATIC bond curvature-to-depth ratio |V''|/|V| = 2/d². But the static
lattice is Earnshaw-null (2426: κ_static < 0), so the real stiffness is DYNAMIC
(the founder's ZBW ponderomotive / Kapitza stabilization). The assumption was:
the dynamic average preserves the static curvature-to-depth ratio (f_stiff =
f_depth, so the ponderomotive prefactor cancels). This patch tests that.

## Three findings

**(F1) The naive Paul-trap shortcut is unreliable — and I caught it.** My first
pass modeled U_sec ∝ |E_static|² and read off a curvature/depth ratio, which
returned g ≈ 0.05–0.13 (would have SUNK the candidate). But the depth extraction
hit the Coulomb singularity at neighbour charges (spurious barrier), and — the
real tell — the eCP lattice site is NOT a static field null: |E_static(site)| =
3.09 ≠ 0. So the "confined-at-a-null" Paul-trap model does not cleanly apply
(Earnshaw again: no static equilibrium at the hand-set geometry). I discarded the
g ≈ 0.1 number rather than report a verdict flip from a broken model. (The 2375/
2381 pattern: the machinery caught its author; correction owned pre-commit.)

**(F2) Small-amplitude limit preserves the ratio.** Averaging the axial bond's
curvature and depth over a symmetric ZBW oscillation of amplitude a (s = a/d):
(k/E)_avg/(k/E)_static → 1 as s → 0 (1.001 at s=0.02, 1.025 at s=0.1). Depth and
curvature pick up the SAME leading factor, they cancel, and 2426's 2R²/d² SURVIVES.
This is the physical regime for a tightly-bound eCP (excursion ≪ bond length).

**(F3) Large-amplitude limit ENHANCES the ratio — the honest surprise.** At
s = 0.8 the factor is ≈ 10, i.e. large-amplitude averaging makes the curvature-
to-depth ratio LARGER, pushing κ_θ/E_bond FURTHER above 0.43, not below. I had
written the docstring expecting "could move either way / could sink it"; the grid
refuted it — every amplitude branch of the tractable model is favorable-to-neutral.

## Net (verdict not moved, but the lean is firmer)
The load-bearing |V''| assumption from 2426 is SUPPORTED, not undermined: **no
tractable amplitude branch drops κ_θ/E_bond below 0.43.** Small-amplitude
preserves the favorable static-shape ratio; large-amplitude enhances it. So the
Kapitza question — the panel target I flagged at 2426 — does not sink the
candidate; if anything it strengthens the favorable make-or-break.

## Honest residual (what would still need doing to HARDEN, not to save)
