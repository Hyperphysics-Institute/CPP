# Reasoning — Patch 2765 (S4-X bundle supplementary adjudication + round close)

**STATUS: verbatim, at-patch.**

The distinguishing-number test, adopted one patch ago as a design
principle for FUTURE packets, got its first live application one turn
later — and in the reverse direction from its design intent. It was
built to catch false execution claims; here it POSITIVELY verified a
true one. The S1 addendum quotes the per-geometry gate five-tuple and
the three-window HNC diagnostic, neither of which appears in the
panel packet — the packet deliberately quoted only the worst gate
value and the far-window comparison — and both match this container's
own runtime output to every decimal. There is no way to produce those
numbers by reading; only by running. The asymmetry with S5 is now
complete and instructive: the seat that admitted it could not verify,
when given the means, produced verification that survives the
strictest test the programme has; the seat that claimed verification
without the means produced numbers that exist nowhere. The
verdict-honesty ordering and the capability ordering were inverted,
which is exactly why the grading standard has to key on evidence
rather than confidence.

The cross-environment reproduction deserves the separate line it
got. Exact decimal agreement across a NumPy minor-version change and
a Python minor-version change was not a claim the programme made —
determinism was claimed within the recorded environment. S1's run
upgrades that for the analyzers and gate (though, as S1 itself
correctly bounds, not yet for bit-identical chain regeneration, where
RNG stream stability across versions is a genuinely separate
question). I adopted S1's own caveat verbatim rather than
paraphrasing it weaker or stronger.

Integrating S2 changed no ruling, which is itself worth recording:
the 2764 adjudication noted that no ruling could flip under any
possible S2 vote except the Q2 split, and the Q2 split had already
been resolved by execution rather than tally. S2's return lands
UPHOLD across the board, so even the counterfactual is moot. Its one
substantive contribution — the k-resolved S_zz-vs-HNC discriminant
with explicit k-range reporting — is a genuinely better instrument
than a prose ruling would have produced, and it runs on data already
archived, so it enters the binding list as requirement 7 at zero
marginal simulation cost. Three seats have now independently demanded
mandatory single-chain regeneration; CONV-006 item 3 was the right
call and the convergence is logged as ratification depth.

Closing the round formally matters for queue hygiene: the bundle was
the blocking item behind which the X3/X4 preregs, the AUTOMATON-1
disposition, and OPEN-DM-CHARGE-1 all queued. The FA-SG-R1 returns
are the founder's only outstanding paste, and the instruction set for
that goes in the turn summary in plain mechanical steps, since the
process (paste one block to five seats, return five labeled replies)
is obvious from inside the protocol and evidently not from outside
it.
