## §2 — What clause 2 means, and why PR3 cannot discharge it

Clause 2 does **not** require memory to be absent; it requires it
**bounded subdominant at d_DP**, so the bridge holds to leading order
there. **Mechanistic reason PR3 does not close it** (offered in place
of deference to the panel's earlier ruling): PR3 measured the STATIC
(zero-frequency) susceptibility; memory is a FINITE-FREQUENCY
property. A system can have an exact zero-frequency response while
carrying large memory at ω > 0. The two tests are orthogonal.
