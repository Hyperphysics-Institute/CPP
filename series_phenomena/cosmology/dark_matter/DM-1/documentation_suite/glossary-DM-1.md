# Glossary — DM-1

## Constants
- **E_eDP / E_hDP / E_qDP** — DP binding energies 88 / 152 / 264 MeV (SF-3/SF-5). First use: §2.
- **m_qDP** — constituent (scattering) mass ≈ 264 MeV; sets σ/m. First use: §2. Related: aggregate-unit mass.
- **V₀, f** — residual two-gluon vdW depth V₀ = f·E_qDP, f ≈ 0.2 → V₀ ≈ 53 MeV. First use: §4.

## Structural terms
- **Cross-Rod** — the selected DM morphology: a 1D rigid axial stack of cube-core elements. First use: §5 (v0.1-R2).
- **Cross-Rod element** — four e:q:q:e hTetras fused through their q:q edges → 8-qCP cubic core + 8-eCP shell;
  m ≈ 4 m_hTetra ~ 1–2 GeV. First use: §5 footnote. Related: hTetra, cube-element.
- **hTetra** — hybrid tetrahedron e:q:q:e; the assembly monomer. Related: qDP, eDP.
- **d_f** — fractal dimension of the aggregate; d_f = 1 (rigid rod). Related: ℓ_p.
- **N (cube-elements)** — the axial element count; the N in σ/m = 0.11·N. First use: §5.

## Mechanism terms
- **σ/m** (\smm) — self-interaction cross-section per mass; 0.11·N·g, target band 0.6–2 cm²/g. First use: §5.
- **ℓ_p (persistence length)** — beam-stiffness scale; ℓ_p = c_geom·(E_bond/kT). First use: §6.
- **E_bond / E_ee** — edge-bond (scission) depth; the freeze-out + fragmentation knob; ∈ [0.8 keV, 2 MeV]. Related: E_qq (stiffer partner).
- **corona** — a hypothetical accreted real-eDP coat that would dilute σ/m; shown null. First use: §5/§6.
- **fragmentation ledger** — the per-collision energy bookkeeping (0860) giving the velocity split.

## Methodology terms
- **Layer A/B/C** — derivation depth: A = full from-substrate; B = EFT/structural derivation; C = consistency/bracketing.
- **LEMMA-DM-CROSS-ROUTE-1** — finding-level lemma: the Cross-Rod is the σ/m-viable DM morphology; UNCONDITIONAL.
- **CONJ-COSMO-1** — the dark-matter conjecture this paper tests; remains NOT-confirmed (no discriminating number yet).
- **make-or-break** — the edge-bond SSV calc that would pin E_bond (external, SF-2/SF-5).
