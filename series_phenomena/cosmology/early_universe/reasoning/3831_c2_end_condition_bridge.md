# Reasoning capture — Patch 3831: C-2's end-condition bridge

*Session 175, 9 Sep 2026, EU lane. Verbatim at-patch capture. Finding: `eu1_derivation/c2_end_condition_bridge.md`. Verify: `scripts/3831_c2_end_condition_bridge.py` (6/6).*

The founder said the edge is the healthier candidate and to proceed, and the handover named the end-condition bridge as C-2's decisive debt, so that was the target. It turned out to be immediate, and the immediacy is itself informative.

With the end condition at one CP per rest-frame Planck sphere, N = ⅓ ln n̄_init, so δN = ⅓ δρ/ρ. That is the whole bridge. A denser region has to expand further before it holds one CP per Planck sphere, so it inflates longer. Density is the one thing the end condition cannot be blind to, because the end condition is a count and density is that count. Three sessions of candidates died against this threshold and the reason they died is now legible in one line: δkT changes the rate but not the count, composition changes the species but not the count, and the threshold reads only the count.

Then I checked my own bookkeeping and found I had got it wrong at 3822. I wrote there that the end-condition wall was "three-for-three with δkT and the count." The count is not blocked by the end condition at all — the count *is* n̄, so it enters δN by exactly the route C-2 uses. It died at 3812 for different reasons: Poisson amplitude and a white spectrum. So the wall is two-for-three, and I have corrected it in the finding and in the frontier.

That correction is worth more than its size, because it relocates C-2. If the count and C-2 are both density perturbations of the initial slice, then C-2 is in the same class as a candidate that is already dead, and it must beat that candidate on the two axes where it died rather than on the axis where the others died. So I computed both.

On amplitude the requirement is δρ/ρ ≈ 1.4×10⁻⁴ and the incoherent floor from 5×10⁹⁷ CPs is about 10⁻⁴⁵ — short by forty-one orders. That reproduces AS-NORMALIZATION's sixty-seven-orders verdict in the re-grounded variables and it establishes something categorical rather than quantitative: no incoherent density mechanism can ever work here, so C-2's coherence is not one of its virtues, it is the only thing keeping it alive.

On spectrum I wanted to stop asking "is it scale-invariant" and instead say exactly which scales matter. Mapping the observed CMB range back through a budget-closed history puts it at 0.002 to 1.0 l_P in the initial ball — the outer 2.7 decades. Nothing near the grid-point spacing is observable; it sits thirty decades below the window. That is a genuinely useful narrowing, because it means the edge is not being asked to produce structure at all scales, only across the outer few decades of the ball, and the edge is precisely an outer-ball phenomenon.

But I did not let that become optimism. A single inward-propagating shell has one characteristic wavenumber and gives Bessel oscillation, not a power law — the same failure that downgraded C-3 two patches ago. So C-2's spectrum debt stands undischarged, and I said so in those words rather than letting the encouraging bridge result blur it.

The thing I most want the next worker to see is §5, which I nearly did not write because it is an observation rather than a result. Every candidate this programme has registered — the count, δkT, composition, frustration, the edge — is a property of the initial slice, stretched afterwards. An initial pattern carries the spectrum it was born with, so the observed spectrum demands that the ignition state itself be near-scale-free across those 2.7 decades. Standard inflation does not meet that demand with an initial condition; it meets it with continuous generation, modes sourced as they cross the horizon with comparable amplitude because H is nearly constant. CPP has no such generator identified and has not looked for one. Two candidates have now failed for the same structural reason, and that is usually the signal that the question is misposed rather than that the answers were unlucky. I registered it as an observation and did not compute on it, because naming a class is not the same as having a member of it.
