## §1 The bridge (verify T1)

The re-grounded count law (3816 §3) has inflation end at one CP per rest-frame Planck sphere, so with n̄_end = 1,

> **N(x) = ⅓ ln n̄_init(x)  ⇒  ζ = δN = ⅓ · δρ/ρ.**

**That is the bridge, and it is immediate.** The end condition is a *count*, so anything that changes the local count changes the number of e-folds needed to dilute to it. A region that starts denser must expand further before it holds one CP per Planck sphere, and it therefore inflates for more e-folds. Density perturbations are the one class of perturbation the end condition cannot ignore.

**This is why C-2 clears the wall that stopped the others.** δkT (3818) changes the *rate* H_eff but leaves n̄ untouched — no bridge. Compositional disorder (3822) changes *which species* occupy the addresses, and the threshold carries no species index — no bridge. An inward-propagating boundary disturbance is a compression/rarefaction wave: it moves CPs, so it changes n̄, so it reaches the end condition. **C-2 is the first registered candidate with a bridge at all.**

The remaining debt can now be posed sharply instead of as "is it scale-invariant?". Mapping observed CMB scales back through a budget-closed history (N = 75, ball radius l_P → the observable radius today):

| today | initial scale in the ball |
|---|---|

> **The CMB probes the outer ~2.7 decades of the pre-ignition ball — scales from ~0.2% of the ball radius up to the ball radius itself.** Nothing near the GP spacing (~10⁻³² l_P) is observable; it lies thirty decades below the window.

So C-2's spectrum debt is precisely: **must the edge's inward disturbance deposit near-scale-free density structure across the outer 2.7 decades, at contrast ~10⁻⁴?**

**A single inward-propagating shell does not.** A shell of radius r carries one characteristic wavenumber k ~ 1/r; in Fourier space it gives oscillatory (spherical-Bessel) structure, not a power law — the same failure mode that downgraded C-3 at 3829. **C-2's spectrum debt is NOT discharged by this patch**, and nothing here should be read as discharging it.

What would discharge it is a mechanism that populates the window rather than one scale: a wave *train* rather than a single front, a cascade that transfers power across scales as the disturbance converges, or continuous regeneration during inflation. Only the third is structurally different in kind (§5). None is computed here (PD-007).

## §5 The structural observation this session earns

Every candidate the corpus has registered — the count, δkT, composition, C-3 (frustration), C-2 (edge) — is a property of the **initial slice**, stretched thereafter. An initial pattern carries whatever spectrum it was born with, and the observed spectrum then demands that the *ignition state itself* be near-scale-free across 2.7 decades. That is a strong demand on an initial condition, and two candidates have now failed it for the same reason: they each carry one characteristic scale.

Standard inflation does not meet this demand with an initial condition. It meets it with **continuous generation**: modes are sourced as they exit the horizon, each with a comparable amplitude because H is nearly constant, so scale-invariance is produced *during* inflation rather than laid down before it. **CPP has no such generator identified**, and the corpus has not looked for one — every candidate to date has been a feature of the start.

Registered as an observation, not a result: **the amplitude problem may be misposed as a search for the right initial pattern.** If so, the productive question is what in the crowding engine could fluctuate anew at each horizon crossing. That is a different question from the one charter Q1 asks, and it is the one 3812's light-mode requirement was already pointing at (a mode with ω ≲ H that keeps being excited, not a pattern that was set once).
