# Glossary — TP-1: The Truncated Photon

Paper-specific terms by category. Each entry: definition; first-use; related terms.

## Constants
- **$\omega_{\max}$ (600-cell band top)** — the intrinsic maximum mode frequency, $\omega_{\max} = \sqrt{\lambda_{\max}}\,c/\ell_P = \sqrt{12}/t_P = 2\sqrt3/t_P \approx 6.43\times10^{43}$ rad/s. First use: §Regularization (eq. bandtop). Related: $\lambda_{\max}$, $t_P$.
- **$\lambda_{\max} = z = 12$** — the largest 600-cell adjacency eigenvalue, equal to the coordination number. First use: §Regularization. Related: QM-5 dispersion, six eigenvalues.
- **$\omega_\gamma$** — optical carrier, $\omega_\gamma/2\pi = 10^{15}$ Hz ($6.283\times10^{15}$ rad/s), the RGS reference scale. First use: §Numerical ceiling.
- **$C$** — the $O(1)$ leading-log coefficient, set by the photon amplitude at the cut and the mode-sum measure; the sole open input (OPEN-TP-1). First use: §Derivation (Lemma).

## Structural terms
- **Truncated photon** — a single photon cut by a fast shutter, becoming a $0\to\infty$ photon-number mixture (RGS). First use: title / Abstract. Related: dynamical Casimir, Fock mixture.
- **Band top** — the hard top of the finite 600-cell phonon/photon band; no modes above it. First use: §Regularization. Related: $\omega_{\max}$, intrinsic regularization.
- **DP-Sea perturbation** — the CPP photon: a propagating disturbance of the Dipole-Pair Sea. First use: §Compatibility. Related: cuttable photon.

## Mechanism terms
- **Intrinsic (finite-spectrum) regularization** — finiteness of $\langle N\rangle$ because the lattice spectrum is finite, not because a cutoff is imposed. First use: §Regularization. Related: band top, QM-5 finite renormalization.
- **Driven-boundary dynamical Casimir** — the shutter as a time-dependent DP-Sea boundary that converts vacuum energy to real photons. First use: §Compatibility. Related: broken time-translation invariance, Nexus.
- **Partial trace under the Nexus** — QM-4 mechanism giving local-simple/global-complex structure. First use: §Compatibility. Related: Unruh-type trace-out.

## Methodology terms
- **Compatibility plus foundational regularization** — the paper-type: embedding a standard result + supplying the finite value its idealization lacks. First use: Abstract. Related: embedding-not-entailment.
- **Embedding (not explanation)** — CPP realizes the structures RGS assume; it does not predict/derive the effect. First use: §Compatibility. Related: accommodation, framework-conditional.
- **RGS-derived, CPP-regularized** — the divergence class comes from the RGS kernel; the finite cutoff comes from the CPP lattice. First use: §Conclusion.
