# reasoning-0950 (verbatim, captured late — see 0942 header note; same provenance)

0949 filed the question of whether V3 consumes the residual and explicitly declined to claim it. This is that re-read.

Started by asking what CAPACITY-1 *names* as its Mechanism-A dependence, rather than what I assumed it used: "per-edge independence of its measure." That is C1's shared-edge step. So the question was narrower than "does V3 use Mechanism A" — it was whether per-edge independence survives A ≠ 0.

Two findings, and the second is the stronger one. First, both residual terms are **per-edge functions** — the midpoint belongs to the edge — so neither couples *distinct* edges, and the factorisation is untouched; only per-edge values change. Second, and I nearly missed it: **C1's spectral bound never references the rate law at all.** It is built from the observable's weights under the pointwise floor. Re-verified against 120 adversarial weightings. And 0828 was specifically hardened for n̂-dependent non-uniform rules — which is exactly what A ≠ 0 produces. The residual lands *inside* the family the bound was built against.

**The error I made, and it would have been a bad one.** My first version of the C2 test tied A to δ. That makes A²δ = δ³, reproduces the A = 0 slope exactly, and would have let me report "the residual changes nothing" for C2. It masks the effect completely. The test refused the claim as I had written it, and I corrected the *claim* rather than the test — with a constant A the slope goes 3.00 → 0.99, a genuine two-order promotion of the steady current.

Had I tied the parameters that way and moved on, this patch would have reported a false robustness. Recording that because the failure mode is invisible in the final numbers: a wrong parameterisation looks like a clean null.

C2 survives anyway, but for a different reason than I first wrote: it is stated *at the physical bias*, and there the magnitude barely moves. The scaling change is a small-δ phenomenon that never reaches φ⁻³.
