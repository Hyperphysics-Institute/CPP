## The question

for a real equal-time pseudoscalar of a classical Markov measure. The one named escape: an order parameter that

## The attack on 0985 fails, three ways

**(a) Positivity is free, so it proves nothing.** |E[e^{iλX}]| ≤ 1 holds for *every* real observable of *every*
probability measure — reversible or not, RP or not (C1). In QCD the positivity of the Euclidean weight is the
hard half of Vafa–Witten because fermions are integrated out; on a classical stochastic substrate it is a
tautology. So the entire content of the VW route, for any observable, sits in whether the physical source is a
phase. Choosing a Moment-odd observable does not change that; it only changes which operator one would have to
argue is sourced by a phase.

**(b) Where the i could come from, the composite is dead.** A real Moment-odd Euclidean observable corresponds
to i × (a Hermitian operator) only under Osterwalder–Schrader reconstruction (∂_τφ = [H, φ] = −i∂_tφ). That
is the one legitimate way a Moment-odd composite acquires a phase source — and OS reconstruction needs Θ_OS
positivity, which Thm A supplies only under detailed balance. Under detailed balance the stationary path measure
is Moment-reversal invariant, so ⟨K⟩ = −⟨K⟩ = 0 exactly, for every g and j (C3). The bound it would give —
"no spontaneous P-odd, T-odd composite" — is already implied by the reversibility that licensed it. Empty.

**(c) Where the composite lives, the i is gone.** At δ ≠ 0, ⟨K⟩ ≠ 0 and odd in δ (C3): it is sourced
*explicitly* by the T-arrow, not spontaneously. Detailed balance fails at O(δ³) (0689), so Thm A is unavailable
and the OS reconstruction that would import the i is unestablished — the very question run 2 probes on the toy
(0989). A phase source cannot be claimed there without H1 itself.

And even granting all of it, **(d) it bounds the wrong object.** A VW bound on K constrains ⟨K⟩, not sign(μ²)
of the equal-time η. The corpus already records the current as sign-*perturbing*, not sign-*setting* (Patch
1100: χ_sym = N/m², sign(μ²) = sign(m²)). So the escape could not have reached the η-verdict even if it had
survived (a)–(c).
