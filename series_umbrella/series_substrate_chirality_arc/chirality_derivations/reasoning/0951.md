# reasoning-0951 (verbatim, captured late — see 0942 header note; same provenance)

The C3 recompute. Deliberately ran it inside **0821's own machinery** rather than rebuilding — a reconstruction risks measuring a different object and then comparing it to the published number as though they were the same quantity.

**How the residual enters, which took some thought.** In 0821 the per-edge variable is `x_e = δ·bias_e + N(0,1)`: the tilt is a per-edge *mean shift*, and it is reversal-odd. The residual A(m·n̂) is reversal-*even* — it multiplies both traversal directions equally, so it cannot shift that mean. It has to enter as a *scale* on the fluctuation instead. The coupling κ between rate modulation and d.o.f. scale is not on file anywhere, so I scanned it rather than picking a value, and reported the worst case.

**Why it barely moves, and this is the part worth keeping.** η is a **sign**. `sign(Σ w_e x_e)` is invariant under positive rescaling of its argument. So a per-edge scale reaches the correlator only through the *relative* weighting within one vertex's read — second order on the shared-d.o.f. fraction ρ that sets `C_nn = (2/π)arcsin(ρ)`. A reversal-even perturbation is close to the worst possible way to try to move a sign-valued order parameter. That is not a numerical accident; it is why the margins are so wide.

**Correcting myself from 0950.** I had flagged C3 as the live risk on the strength of a 10.9% shift in the stationary measure π. That flag was aimed slightly off: K_lift is not computed from π. The recompute was still worth doing — "not computed from π" needed checking rather than asserting — but the honest record is that I over-weighted the risk one patch earlier, and I wrote that into the artifact rather than letting the successful result cover it.
