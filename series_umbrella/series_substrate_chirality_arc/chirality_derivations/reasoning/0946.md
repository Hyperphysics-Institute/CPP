# reasoning-0946 (verbatim, captured late — see 0942 header note; same provenance)

The founder asked whether the travel-distance asymmetry resolves the W⁰'s chirality. The trap in the question is that the answer *feels* like yes — we had just found a real asymmetry, and chirality is an asymmetry.

Went to parity class first, because that is where MERGE-2 already ruled once. If `sign(δ)` is P-even/T-odd, then the asymmetry is an arrow and arrows are not handednesses. The question was whether that generalises to the W⁰ or whether the W-bracelet context changes it.

Built the objects rather than arguing. Vertex stabiliser from the lattice: order 120, and **60 orientation-reversing elements**. So the bare substrate is achiral — it has no handedness to donate, whatever else is true. That alone nearly settles it.

Then the sharper step: there is an orientation-reversing element that *fixes n̂* and carries the twelve first-shell directions to themselves. So the configuration MA.1 is defined on has a mirror through it, and the rate law is invariant under that mirror for every direction. And the O(δ¹) current is carried to *itself* by the mirror — a polar vector, a flow direction, an arrow.

A chirality needs a pseudoscalar. From n̂ alone you cannot build one: a 4D pseudoscalar needs four independent vectors.

**What the question paid for.** Checking it surfaced that the founder's own W⁰ ruling fixes *what* sits on the ring and not the *order*. Enumerated: 4 arrangements up to rotation, 3 up to rotation-and-reflection, so exactly one chiral pair. That is where a W⁰ handedness would live if it has one — not in the travel asymmetry.

Also found that 0924's stated worry ("degenerating at n̂-extremal vertices") points the wrong way: the poles are the *best* case, p = 12, because the stabiliser there is the full local I_h acting transitively on all twelve. Recorded that rather than quietly using the right shells.
