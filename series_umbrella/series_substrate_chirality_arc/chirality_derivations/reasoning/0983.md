## A probe of the right object, so this is not only a reading

If H1 is Θ_OS-positivity, the toy measure 4022 built can be asked the right question: for a single-time
observable A, ⟨Θ_OS(A) A⟩ = ⟨A, Π e^{2tQ} A⟩_π. I computed the symmetrised pairing's spectrum against δ and
t. Detailed balance is exact at δ = 0 (Theorem A reproduced) and its defect is **exactly O(δ³)** at small δ
— TARROW-2's current, seen from the other side. The tilted generator keeps a real spectrum (a random tilt of
a thousandth the size does not, so the check can see it). The pairing is positive at every δ for t ≤ 0.5.
At δ = 0.35, t = 1 the minimum eigenvalue is −3.5 × 10⁻¹⁵ and does not move between 30 and 50 digits from
float-precision rates; an exact-rate run was still running at patch time and is **not claimed**. This is a
necessary condition only, on [PCD-EXT], single walker.
