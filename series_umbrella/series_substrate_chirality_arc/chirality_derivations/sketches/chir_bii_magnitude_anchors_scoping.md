## §3 The χ normalization reconciliation (φ⁻¹ vs φ⁻³) — RESOLVED

### §3.1 The apparent tension

BRIDGE-1's magnitude proposition carries an honest flag (and falsifier **B4**): *"reconciling Capotauro's χ ≈ φ⁻¹ normalization with CHI-1's |χ| = φ⁻³ is a B-ii task, not settled here."* On its face this looks like two registered values for one quantity — a live discrepancy that would break the magnitude thread.

### §3.2 The resolution: there is no live tension

There is **one** live magnitude, χ = φ⁻³, and it is unambiguous across every current source: FI-C-9 (registered Session 87 Patch 0381, |χ| = φ⁻³); CHI-1 (rigorous derivation, χ = φ⁻³, excludes the alternatives); Capotauro v1.0 and v2.0 (|χ| = φ⁻³ ≈ 0.236 throughout, feeding |M| = χ/6 = φ⁻³/6 in all three sectors). The value **φ⁻¹ is not a competing normalization of the live magnitude**; it is two distinct things:

1. **A registered DEAD END.** The original χ ≈ φ⁻¹ conjecture (carried as a placeholder Sessions 1–85) was **abandoned at Session 86** via three independent diagnostics (Findings C-1/C-2/C-3, Capotauro development record):
   - **C-1 (geometric inconsistency):** φ⁻¹ *is the 600-cell edge-length scale*; a chirality bias of that magnitude would produce chirality-dependent edge lengths, distorting the H₄ geometric structure itself — violating the structure-preservation constraint (capotauro.tex explicitly rejects the |χ| = φ⁻¹ case on exactly this ground).
   - **C-2 (empirical mismatch):** back-derivation from the Δp_LR ≈ 0.04 anchor is inconsistent with χ = φ⁻¹ (≈ 0.618).
   - **C-3 (arithmetic correction, Patch 0378):** the archive's intermediate χ = φ⁻² derivation had a one-step error (a lost factor 1/φ); correcting it yields **χ = φ⁻³**, the value that became FI-C-9.
2. **A DISTANCE scale, not a magnitude.** φ⁻¹ is the vertex-to-vertex distance of the 600-cell's first (icosahedral vertex-figure) shell. CHI-1 *uses* this distance as an **input** and **builds χ = φ⁻³ from it** as the symmetric bias of the two nearest shells (φ⁻¹, 1):
   > **χ = (1 − φ⁻¹)/(1 + φ⁻¹) = φ⁻²/φ = φ⁻³ ≈ 0.236.**
   The dead conjecture's error was precisely conflating the **input distance** (φ⁻¹) with the **output bias/magnitude** (φ⁻³). They differ by exactly the symmetric-bias map.

So φ⁻¹ (distance) → χ = φ⁻³ (bias) is not a tension but a **derivation step**; and φ⁻¹-as-magnitude is a **superseded conjecture**, not a live normalization. **The reconciliation: no live tension exists.**
