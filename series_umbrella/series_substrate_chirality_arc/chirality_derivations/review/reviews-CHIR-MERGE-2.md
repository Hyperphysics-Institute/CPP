## Part 2: Cross-reviewer synthesis

**On the load-bearing G2 (δ T-odd) — the real content of the cycle.** All three reviewers actually agree on the *structure*; they disagree on whether v1.0 *grounds* it. ChatGPT is correct that **MA.1 alone does not force δ T-odd** — Interpretation B (δ as a static T-even anisotropy) is logically available *if* `j_net` is allowed to be a T-even static order parameter. Grok and Copilot are correct that within CPP δ *is* T-odd — but the decisive reason is not the rate law in isolation; it is two things v1.0 left implicit:
1. **δ couples *oddly* to `ê`** (`r(ê) ≠ r(−ê)`). ChatGPT's analogy class — conductivity anisotropy, crystal-axis preference — are all *even* in direction (`r(ê) = r(−ê)`; a nematic axis has `n ≡ −n`). Mechanism A's δ is a *polar, odd-in-direction* propagation bias (faster one way than the other), i.e. drift-/flux-like, not anisotropy-like. This excludes ChatGPT's *even* static-anisotropy class outright.
2. **The registered MERGE-α identification.** THEO-CHIR-MERGE-1 (MERGE-α) + THEO-DSL-3 identify the substrate current `j_net` with the **thermodynamic causal arrow** (manifestation iv). An arrow is T-odd by definition. Since `j_net = (6δ/φ²)n̂` with `n̂` T-even, δ is T-odd. ChatGPT's Interpretation B (`j_net` a T-even static order parameter) is therefore not a neutral alternative — **it is a rejection of MERGE-α.**

So the honest status: **δ T-odd is forced *conditional on* MERGE-α's arrow-identification of `j_net`.** The result inherits MERGE-α's Layer-2.5 viability ceiling. If MERGE-α's identification fails (j_net is a static T-even polar order parameter, not the arrow), δ is T-even and the verdict reverts to M3 — exactly ChatGPT's Interpretation B, now located precisely as the MERGE-α viability ceiling rather than a free choice. The verdict **M1-χ stands** (the framework commits to MERGE-α), stated conditionally.

**On the category-mismatch (Consequence 2).** ChatGPT and Copilot converge: direct **identification** `sign(δ) = sign(n̂)` is forbidden (different P,T characters — airtight, both agree); a covariant **tie** would require an independent mediator of character (P-odd, T-odd); **no such independent primitive exists** in the current framework (achiral 600-cell ⇒ no primitive pseudoscalar beyond FI-C-9; `σ_cycle`/`ω_PCD` are not independent of what is being decomposed). So the corollary is sound in practice but v1.0's universal wording ("no P,T-covariant relation **can** equate them or render one a function of the other") overstates. Correct statement: *no direct identification; and no presently-available covariant tie, because the framework contains no independent (P-odd,T-odd) mediator.*

**On achirality (G3) and the decomposition.** Confirmed twice independently (Grok Tier 3 + Copilot Tier 2 / structural). No second primitive pseudoscalar. The decomposition strictly follows from the binary-sign characters. Solid.

**Pattern note (`AI_team_expectations.md` §4).** ChatGPT-the-cautious tempering a confident pair (Grok "defect-free," Copilot "logically sound") is a clean meta-review catch: the dissent did not break the verdict but exposed an unstated premise (the `j_net`-arrow identification) and an over-strong corollary. Both are now explicit in v1.1. This is the review process working as intended.
