The η construction (0821) made the per-link correlation analytically tractable, so I didn't have to sample-and-hope. η_v is the sign of a weighted sum of per-edge-independent variables, so the only fluctuating input shared by neighbours v,w is the single edge variable x_{vw} — common neighbours contribute different (independent) edge variables. That law immediately shows the proposed route is FALSE: more-local observables are MORE strongly per-link correlated, not less (m=4 gives 0.16, m=12 gives 0.053). The {4,6,8,12} scan looked like "more-local -> weaker" only because it averaged each link's correlation over the many links where the small-m read set drops the shared edge — a dilution artefact of the mean, not the per-edge entry. So |C(m')| <= 0.053 entrywise does not hold, and a larger scan would have kept hiding it behind the same averaging. I want to be plain that this means correcting the chirality lane's own proposed sufficient condition, not just executing it.

But the conclusion survives, via the right invariant. Perron gives rho(M) <= rho(|M|) <= max row sum — which is exactly what makes sign-coherence and non-uniformity (0918's worry (b)) irrelevant, because we bound |M|. Each vertex reads m edges, so <= m reciprocal links each <= (2/π)arcsin(1/m), hence rho(M(m)) <= R(m) = m*(2/π)arcsin(1/m). R(m) is decreasing, R(1)=1, R(2)=2/3, R(inf)=2/π — so R(m)<1 for every m>=2, critical only at the degenerate single edge. The fewer-but-stronger trade-off is exact: row sum stays ~2/π, reaching 1 only at m=1. I verified rho(M) numerically for the nn-only coupling: 0.59-0.64 for m=2..12, ~1.0 at m=1, matching R(m).

Building M as nn-only fixed it and reproduced 0918's Axis-1 number. Worth recording because the full-C-vs-coupling distinction is exactly the kind of thing that could have produced a false super-critical alarm.
