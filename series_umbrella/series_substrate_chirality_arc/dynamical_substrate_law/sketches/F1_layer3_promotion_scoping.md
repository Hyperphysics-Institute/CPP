## §1 Purpose and scope

### §1.1 Why open a Layer 3 promotion scoping sketch now

The F.1 sub-question reached substantive Layer 2 closure at Patch 0539 (§15.2 framing: "SUBSTANTIVE SKETCH-LEVEL CLOSURE at Layer 2 under the minimal-local-first-order realization framework, pending Layer 3 promotion + supplementary work on the 7 open sub-questions and higher-order extensions"). The next substantive priority registered in the Patch 0539 forward queue (item B) is Layer 3 promotion work.

Layer 3 promotion is described as "each Layer 3 promotion is its own gated trajectory" — meaning the Layer 3 promotion arc is not a single closure but a sequence of separate gated closures, each promoting one Layer 2 sketch closure to Layer 3 theorem-level rigor with framework axiomatization, explicit derivations, and reduced dependence on framework inheritance.

A Layer 3 promotion scoping sketch parallel to Patch 0531's Phase 2 foundations work scoping is the natural opening move: enumerate the targets, identify dependencies, establish priority ordering, register anti-priorities. The scoping makes the Layer 3 promotion arc structured rather than ad hoc.

### §1.2 What Layer 3 promotion means vs sketch Layer 2 closure

Layer 3 promotion adds three kinds of rigor beyond sketch Layer 2:

| Dimension | Sketch Layer 2 (current state of B.1/B.2/B.3 closures) | Layer 3 promotion target |
|---|---|---|
| Algebraic derivations | Inherits identities from framework references (e.g., "icosahedron central symmetry" cited; numerical verification at machine precision) | Explicit step-by-step algebraic proof from primitive geometric facts; no framework inheritance citations for load-bearing identities |
| Framework axiomatization | Uses framework inheritance (e.g., Reading C + framework matter-content homogeneity, framework local-current-definition + standard PT propagation) | Independent axiomatization at theorem-level; framework inheritances become derived results rather than inherited primitives |
| Scope qualifiers | "Within the minimal-local-first-order realization framework" / "within finite-dimensional standard Wigner-Eckart framework" / "with numerical verification at machine precision but not substitute for Layer 3 algebraic derivation" | Either the scope qualifier is removed (if Layer 3 work expands the scope) or the qualifier is itself derived as a framework property (if Layer 3 work axiomatizes the framework boundary) |

The Patch 0538 §14 calibration items identified seven calibration items that map directly to Layer 3 promotion targets. The Layer 3 promotion arc resolves those calibration items by upgrading the underlying closures from sketch Layer 2 to Layer 3 rigor with the scope qualifiers either dropped or framework-axiomatized.

### §1.3 What Layer 3 promotion does NOT do

Layer 3 promotion does NOT:

- Authorize F.1 flagship paper assembly — that requires Layer 3 arc completion + reviewer-pause cycle at Layer 3 + status upgrade Patch (per §17 codified discipline applied to Layer 3 closure milestone).
- Authorize F.2 / F.3 substantive content — those remain DEFERRED at decision-gate level per Patch 0539 §15.5 of decision gate.
- Address higher-order extensions (B.1.q6 territory) — Layer 3 promotion works at the same order as the sketch Layer 2 closures (typically $\mathcal{O}(\delta)$); $\mathcal{O}(\delta^2)$ work is separate.
- Address the long-term programme target (chirality scale from polytope geometry) — that remains REGISTERED + DEFERRED.

The Layer 3 promotion arc is bounded to the existing seven sub-question closures from Patches 0532–0537; supplementary sub-questions (B.1.q6, B.2.q2–q4, B.3.q2–q4) are separate work.
