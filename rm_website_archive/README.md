# RM Website Archive

CPP articles archived from **renaissance-ministries.com** (WordPress).

These are the full-text versions of Thomas's CPP papers as published on the Renaissance Ministries website, exported with v2 YAML frontmatter (domains, topics, scripture references, people mentions, thesis extraction).

## Contents

- **107 markdown files** covering:
  - Full manuscript versions (Version 1.0 through 4.1, multi-part)
  - Topic-specific Vixra papers (electroweak, gravity, dark matter, consciousness, etc.)
  - Supplementary articles (glossary, meditations, validation protocols)

## Frontmatter Fields

Each file contains a YAML frontmatter block with:
- `title`, `author`, `date`, `module` (always CPP)
- `domains` — top-level classification (physics, philosophy, theology)
- `topics` — granular tags from ~300-term taxonomy
- `scripture` — auto-extracted biblical references (where present)
- `mentions` — people/figures referenced
- `thesis` — auto-extracted thesis sentence
- `source_url` — link to the original WordPress post
- `wp_id`, `wp_slug` — WordPress identifiers
