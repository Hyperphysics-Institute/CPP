## 2. WHAT IS BEING TESTED

**The A3′ completion (Option B).** A3′ calls LSP′ = (Φ, V_i, Q_ij) "the complete set of
rotationally protected irreps." That enumeration is over the **rotation** group I, where polar
and axial vectors are the same irrep T₁. Under the full group I_h they are inequivalent
(T₁_u vs T₁_g, overlap exactly 0 — verified at 4113). **A3′ carries T₁_u only.** The proposal
adds the missing **T₁_g axial-vector channel A_i** (the CP's ZBW spin), matched across:

- **A1′** — CPs carry an axial-vector attribute
- **A3′** — LSP′ = (x, t; Φ, V_i, Q_ij, **A_i**)
- **AP-4** — DI-bit content {origin, E, S, **A**}

Then b ~ A·V is derived, not postulated.

## 5. FRAMING NOTE — read before running the suite

The authorization says *confirm*. **The programme above is written to test.** A suite that can
only confirm returns a pass whether or not the axiom is true, which would make the
authorization worthless. Three tests (A3G-1/2/3) are falsifiers; A3G-6 and A3G-9 have
determinate failure branches.

This follows PD-008 — press the work to the end, state the result, mark which branch was the
convenient one — and the founder's own adoption standard at 4093: **adopt only after a clean
win.** If confirmation-only was intended, that is a different instruction and should be given
explicitly. It has not been assumed here.

## 6. Method warning inherited from this session

Two of this session's patches were self-corrections with an identical cause: **a claim tested
on generic inputs rather than on the corpus's actual objects** (4096→4102; 4109→4110). CPP's
structures are highly symmetric by construction and symmetry is exactly what kills invariants,
so random-input tests **systematically over-report availability**. Every test above must be run
against real CPP structures — the icosahedral and dodecahedral cages, the D6 bracelet, the
actual sea — not against random matrices or generic configurations.
