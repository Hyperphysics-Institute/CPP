## Nomenclature

**Series codes:**

| Code | Series |
|------|--------|
| SS | Strong Sector |
| SM | Standard Model Emergence (600-cell series) |
| SR | Special Relativity |
| EW | Electroweak |
| QM | Quantum Mechanics |
| SD | Superdeterminism / Foundations |

**Paper types:**

| Type | Meaning |
|------|---------|
| [Paper] | Contains at least one proved theorem |
| [TN] Technical Note | Bridge, historical, or methodological — no primary theorem |
| [CC] Commentary | Response to experiment, prediction paper, discussion |

**Numbering within series:** Sequential integers. Technical notes are numbered as `SM-TN-1`, `SM-TN-2`, etc. Commentary papers are numbered as `CC-1`, `CC-2`, etc. across all series (they are cross-cutting by nature).
