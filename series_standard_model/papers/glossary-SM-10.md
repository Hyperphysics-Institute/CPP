# Glossary — SM-10: First-Principles Quark Mass from FEM Chain Network Simulation

**Paper:** SM-10 v0.1 (9 April 2026, proposal)
**Series:** Standard Model

---

**FEM (Finite Element Method)** — Computational method for solving boundary-value problems on discrete domains. Here applied to the chain network inside quark cages.

**Organised DP** — A Dipole Pair recruited from the Sea into the chain network. The central observable of the simulation. Mass = N_organised × M₀.

**DP Sea density (ρ_Sea)** — The number density of available Dipole Pairs in the confinement volume. Open parameter to be determined by convergence testing.

**Thermalization distance (r_therm)** — The distance beyond which the organised chain's SSV field falls below the Sea's thermal noise. Sets the outer boundary of organisation.

**Chain formation rule** — The local pairing rule: each CP bonds to the nearest opposite-polarity unbound CP. Phase 1 uses nearest-neighbor; Phase 2 tests energetic optimisation.

**Circular validation** — The error of comparing simulation DP counts to V^(7/3)-derived targets instead of directly to PDG mass ratios. Identified by Sonnet; corrected in v1.0 success criteria.

**Fractal dimension** — The effective dimensionality of the chain network, expected between 2 and 3 (corresponding to the 7/3 exponent). A measurable secondary output.

**Convergence test** — Running the simulation across a range of ρ_Sea values to verify that DP count ratios stabilise above some threshold density.
