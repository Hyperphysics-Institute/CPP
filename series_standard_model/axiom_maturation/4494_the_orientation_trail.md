## 3. The trail and the fringes

### 3.1 What he describes

*Claude's reading of "there is a trail left":* the DPs the core has passed are left turned end for end relative to how they pointed when it approached, at
no energy cost. A permanent dipole that follows a passing charge does swing through 180° between far ahead and far behind, at any distance of closest
approach; an induced (stretched) dipole would relax toward zero instead. Whether the turned state persists once the core is far away is what decides the
fringes (§3.3). The atom is neutral, so beyond its electron cloud the core's field is screened, and the turned volume is roughly a tube of atomic radius
along its path; that still holds vast numbers of DPs.

### 3.2 If the turn stays put, it tells which path

If the turned DPs stay turned and lie only in the arm the core took, the Sea's final state differs according to the path, and the fringe visibility is the
overlap of the two final states (the standard decoherence factor, bounded by Englert's relation, 4445, 4490). The script's table, verbatim (D-11):

```
ORIENTATION-TRAIL TABLE (Patch 4494)  V = |Tr(rho U_A^+ U_B)|
T1 one DP flipped, core's arm only         theta = pi, z start  V = 0.0000  PASS
T1 same, random starting orientation       theta = pi, mixed    V = 0.0000  PASS
T1 same, start along the turning axis      theta = pi, x start  V = 1.0000  PASS
T2 1e6 DPs turned 1e-3 rad, core's arm     pure start           V = 0.8825  PASS
T3 same, random starting orientations      mixed start          V = 0.8825  PASS
T4 both arms trailed alike                 theta = pi           V = 1.0000  PASS
T5 trail undone before recombination       flip then unflip     V = 1.0000  PASS
7/7 PASS
```

(Each DP's orientation is modelled as a two-state system; V = |Tr(ρ U_A† U_B)|, where U_A and U_B are what the Sea undergoes if the core takes arm A or arm
B. A full turn removes the overlap for a random start and for any start across the turning axis; only a start along the axis is untouched, so the result
holds averaged over orientations, not for every one. T3: not knowing the starting orientations does not hide the trail. The model is fair for the
front-to-rear swing; the initial alignment of random DPs toward the approaching core lowers their entropy and is not a rotation on the DP alone, so its record
would move into the atom or the Sea.) On this reading, a single fully turned DP, in the core's arm only, removes the fringes on average.

**What the experiments say.** Atom interferometers have shown interference with wave packets separated by up to 54 cm over about a second (Kovachy et al.,
Nature 528, 530, 2015). Stamper-Kurn, Marti and Müller (2016) pointed out that high contrast alone does not prove coherence *between* the arms: a which-path
localization would leave high-contrast fringes with a phase that changes randomly from shot to shot. The authors replied (arXiv:1607.03485) that the
result still constrains any modification that would reduce contrast between widely separated arms. The conclusion here rests instead on experiments that
read a determinate phase across separated arms: a dual interferometer with wave packets up to 16 cm apart measured a 1 rad phase shift from a nearby source
mass (Asenbaum et al., Phys. Rev. Lett. 118, 183602, 2017), and light-pulse gravimeters with arms millimetres apart read gravity from the phase (Peters,
Chung and Chu 1999, in 4442). Coherence between arms tens of centimetres apart is established; whatever the core leaves in one arm must not tell the arms
apart.

### 3.3 The readings that keep the fringes

- **(P) Present-field — the most favourable reading (D-15).** Both of his bullets say the opposite charge is "drawn toward the atomic core," ahead of it and
  behind it. That is a rule set by where the core is *now*, which is 4493 §3's premise for why the paths can rejoin. On this reading the "transposition" is
  the front-to-rear asymmetry of the pattern that travels with the core: rear DPs point forward because the core is now ahead of them. Once the core is past
  the point where the arms meet, the DPs along both arms lie behind it and point toward it alike, whichever arm it took: V = 1, with nothing required of the
  arcs. The trail tells nothing about the path **if a DP's orientation always follows the core's present position (no memory)**; it tells which path **if
  the turned orientation stays put after the pull fades**. (Claude's reading.)
- **(T4) Both arms trailed alike** — needed only if the turn stays put. Whichever arm the core takes, the DPs along both arms would have to end transposed
  the same way, which needs the KE/DP-arcs in the arm without the core to turn their DPs as the core does in its own arm (4464, 4491). That would answer
  4493's far-path puzzle in part. Its hidden cost: the core's electrical effect would then be present in both arms, and would act on probes in the empty arm
  (for example in an ion interferometer). (Claude's reading.)

  `rm_website_archive/`), would not erase the record. Later dynamics that are the same on both paths leave the overlap unchanged; randomization by coupling to

- **"A flipped random DP looks like an unflipped one."** True of the statistics, not of the microstate; the overlap depends on the microstate (row T3 in
  words).
- **A plus–minus symmetry.** Swapping a DP's + and − CPs gives a different configuration, so a symmetry protects nothing unless the Sea's whole final state is

- **The trail outside the ledger.** One might say the released DP is no longer entangled, so its turned orientation does not count. But a turned DP whose
