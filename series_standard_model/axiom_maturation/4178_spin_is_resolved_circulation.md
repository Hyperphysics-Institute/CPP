# The Structural Argument Fails on CPP's Own ZBW Radius

**Patch:** 4178. **Lane:** EW/GR. **Session:** 234.
**Tests:** the founder's 4178 ruling, at the condition it names.
**Challenges:** the completeness argument of 4172 §§1–3, which I wrote.

## 1. The ruling's condition is the whole test

The founder keeps A3′ on realism: *"if the argument describes reality, that seems useful."* Setting
observability aside is defensible. But then **the structural argument is the only support left**, and
it becomes the thing to check. Per PD-008, checking it is the work, not accepting the ruling.

The argument (4172 §§1–3, mine): **spin density is matter's second conserved current, absorbed in
the Belinfante tensor and not independently represented in T_μν — so it is a source with no channel.**

## 2. Why that argument holds in Einstein–Cartan and not here

In Einstein–Cartan, spin is an independent source because **Dirac spin is not resolvable
circulation.** It is intrinsic: there is no charge going round a loop.

**In CPP there is.** `master_glossary`, verbatim:

> *"**ZBW smearing** — the time-averaged spatial distribution of a quark's charge due to its **ZBW
> orbital motion** around its cage vertex. Smearing radius **r_ZBW = ħc/m_const ≈ 0.631 fm**."*

**0.631 fm = 6.31×10⁻¹⁶ m, against a grid spacing of l_P/10³⁰ ≈ 1.6×10⁻⁶⁵ m** (c01, confirmed 4168).
**The ZBW orbit spans ~4×10⁴⁹ grid spacings.** It is not a point, not sub-resolution, and not
intrinsic. **It is a resolved circulating current.**

And a resolved circulating current's angular momentum is **orbital**. It lives in the momentum
density T_0i — which A3′ already broadcasts, as **V_i**.

> **CPP's spin is not an independent source. It is circulation the packet already resolves.**

## 3. The duplication, stated exactly

The axial degree of freedom is already present in the packet. Patch 4141 §2 named it and I then lost
track of it: from V_i one builds the **gravito-magnetic field B^G = ∇ × V_i**, which is **axial**.

So the packet already contains an axial field — a *derived* one, constrained by V_i. **A_i adds an
*independent* axial field where a derived one exists.** That is not completing an enumeration; it is
**adding a degree of freedom**, and it needs a justification the "no channel" argument does not
supply.

## 4. What this does and does not overturn

**It does not refute χ₄, and it does not touch A1′.** A1′'s carried attribute — the ZBW
circulation's *sense* — is a sign, not a field. A sense is not obtainable from |∇ × V_i| alone, and b
needs it (4165). **A1′ stands exactly as 4177 left it: load-bearing and cheap.**

**It does undercut the one support A3′ had left.** Under the founder's own criterion — *does the
argument describe reality?* — the answer on CPP's own ZBW radius is that **the reality being
described is already in V_i.**

**What could still save it:** if A_i and ∇ × V_i are genuinely independent — if the lattice's axial
content is not fixed by the polar channel's curl — then A_i is a new fact about the world rather than
a duplicate. **That is checkable and I have not checked it**: it needs the shell-sum's action on both
channels compared. Filed as **TODO-4178-INDEPENDENCE**, and it is now the single question the
channel's existence rests on.
