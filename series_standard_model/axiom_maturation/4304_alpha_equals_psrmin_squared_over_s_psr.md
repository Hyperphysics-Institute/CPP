## 1. His count, in 4301's relation

N = 4π (PSR_min/s)², one DI-bit per GP on a one-GP-deep spherical surface of radius PSR_min. With the conversion-free
relation α = N s/(4π PSR):

  **α = PSR_min² / (s · PSR),  i.e.  PSR_min = √(α · s · PSR).**

The black-hole PSR would be √α times the geometric mean of the GP spacing and the ordinary PSR.

```

  GR-FE-1: PSR/s = 1e30    packing floor PSR_min = s     : N = 1.3e+01  alpha = 1.0e-30
  GR-FE-1: PSR/s = 1e30    alpha = 1/137 needs PSR_min = 8.54e-17 PSR = 8.5e+13 GP spacings = 1.4e-51 m;  N = 9.2e+28
```

Neither floor on file gives α: the l_P/2 register floor (which the founder has said carries no conceptual weight) misses
by 10²⁹, and a one-GP packing floor by 10⁻³⁰. **α = 1/137 predicts PSR_min ≈ 10⁻¹⁶ PSR** (about 10¹⁴ GP spacings,
10⁻⁵¹ m), with N ≈ 10²⁹–10³¹ per Moment, the same N as 4301. Whether the registered SR-1 PSR(SSV_abs) formula can reach
10⁻¹⁶ at black-hole stress is a check for the GR lane (filed).

## 2. How the spreading works (corpus)

R-OUTWARD-FANOUT (founder, 14 Aug 2026; Patch 3135): at every hop a GP's DI-bits are **shared equally** among its outward
neighbours (radial and radial-plus-tangential, never anti-radial). Shares split; they do not multiply. So the count N is
conserved outward and thins as 1/r², which is what 4301 assumed. The same rule *derives* the shell's thickness from
path-length variation, which the founder had predicted at ~10%. Pass 3 (subpsr_pass3_fanout_results.md) found
σ_r/⟨r⟩ = 0.093–0.076 for 6–22 hops, about 0.096 at moderate hop counts.

Spread through the 10% shell, the α-consistent N gives each GP in the band a DI-bit from a given source about once in
10⁶¹–10⁶⁵ Moments; delivery to any particular GP is by re-radiation, as the founder said.
