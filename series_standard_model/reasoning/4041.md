# Reasoning — Patch 4041 (built the thing, failed to measure it)

**STATUS: verbatim, at patch.**

## The idea

A regular icosahedron is **achiral** — 60 improper symmetries of its own. So **z = 12 icosahedral forces an
achiral first shell**, whatever the rest of the structure does. That is not an obstacle; it is a
localisation. **The chirality has to live in the second shell.**

And there is a clean way to put it there. A **generic** point has a **60**-point orbit under the chiral
group I, where under I_h it would have **120**. A 60-point orbit therefore cannot be closed under any
improper operation — it is chiral by counting.

## Built

Icosahedron (12) + generic I-orbit (60) = **72 points. Proper symmetries 60, improper 0.**

Every control gives 60 improper: 12 + a 5-fold-axis orbit, 12 + a 3-fold-axis orbit, the bare icosahedron.
Special positions give small orbits (12, 20) and the cluster stays achiral; only the generic seed works.

**This is 4038's target at cluster scale, and the first object in this arc that is actually chiral with the
right rotation group.**

**Scope of the proof**, stated because "I searched and found none" has been wrong repeatedly today: the
search covers I_h's improper coset {−R : R ∈ I}. That is sufficient — a point group containing I together
with any improper element has order ≥ 120, and the only finite point group containing I at index 2 is I_h.
So zero here means genuinely no improper symmetry, not merely none of the ones I looked at.

## And then I could not measure it

**The 3-hop path estimator returned 0.** Not because the cluster is achiral — because it has **~240 paths**
to work with. Nearest-neighbour distance is 0.638 while shell 2 sits at 1.9, so the neighbour graph is far
too sparse for an estimator built on the 600-cell's 12-regular graph.

**Reporting that zero as a result would have been the worst error available today** — a null from an
instrument that cannot see, presented as a null from the world. I have written four patches about exactly
this shape and nearly committed it again.

**The continuous chirality measure failed too**, differently: by random rotation search it floors at ~0.03
for the chiral cluster **and** for the exactly-achiral control. An achiral set must score exactly 0, so the
measure is sampling-limited rather than measuring. It needs local optimisation seeded from the group
elements. Not done.

## What is and is not achieved

**Achieved:** a structure chiral by an exact group count, with icosahedral rotation symmetry and an achiral
z = 12 first shell.

**Not achieved: a lattice.** This is a 72-point cluster. Extending it to a space-filling structure while
keeping z = 12 at every point is the remaining work — and 4034's trichotomy says that is exactly where the
difficulty lives, so the hard part is still ahead rather than behind.

**Not achieved: a quantified chirality.** The group count proves chirality; it says nothing about how much,
and how much is what a physical prediction would need.

**FI-C-9 = V3 stands.** This removes an obstruction and builds a candidate. It does not derive a handedness,
and after a day in which the tempting reading has been wrong six times, that distinction is the one worth
keeping.
