# Reasoning — Patch 4043 (I agree with the reframe, and here is what it costs)

**STATUS: verbatim, at patch.**

## Where I agree

FI-C-9 = V3 says chirality is **primitive**. A chiral substrate is **exactly what a primitive chirality
looks like structurally**. So the founder's reframe is right, and it is an upgrade rather than a
restatement: V3 moves from *put in by hand* to *a property of the substrate's structure*, which is more
explanatory. 4041 and 4042 give it a concrete realisation.

## The audit, run before the construction

Dodecahedral-shell mentions: **SF-4 twenty, SF-3 five, SM-2 five, SR-1 four, SF-1 zero.**

**SF-1 — the cleanest prediction the programme has — reaches no further than shell 1**, consistent with
4037's finding that it runs on a three-vertex triangle. A lattice that destroyed the dodecahedral shell
would cost the **neutrino sector** most.

*A draft of that check asserted SF-4 and SR-1 both used the second shell heavily, and failed on SR-1. The
claim came from misreading my own column headers in an exploratory grep — the column I read as "second
shell" was counting "20 vertices". SR-1 mentions the second shell zero times. Recorded because misreading
one's own scratch output is a failure mode worth naming, and it is the fifth time today a check has caught
me rather than the claim.*

## And it need not cost them anything

**Shells at different radii are independent.** Shell 1 icosahedron (12, r = 1.00), shell 2 dodecahedron
(20, r = 1.62), shell 3 generic I-orbit (60, r = 2.40):

| set | improper | CCM |
|---|---|---|
| S1 | 60 | 0.00000000 |
| S1+S2 | 60 | 0.00000000 |
| **S1+S2+S3** | **0** | **0.01121** |

**Both shells CPP uses survive intact, and the chirality is carried entirely by a third shell that no
derivation references.** That is the substantive answer.

## Three qualifications, none small

**(1) Still a cluster, not a lattice.** 4034's trichotomy is untouched. The extension problem sits exactly
where it was, and it is the hard part.

**(2) The third shell is a new postulate.** CPP does not currently have a 60-point shell. The claim is that
the change is **additive** — nothing existing breaks — not that nothing is added. I want that distinction
kept, because "nothing breaks" reads like "nothing is needed" and it is not the same statement.

**(3) The magnitude is still free.** 4042: tunable 0.012–0.187. Chirality becomes a **structural
parameter** rather than an unexplained sign, which is progress — **but a parameter is not a prediction
until one calibration buys more than one number**, which is precisely the standard SF-1 already meets.

## Where it would stop being bookkeeping

SR-1's dispersion machinery **sums over shells** — R4's own words: *finite shells suppress the icosahedral
anisotropy tower one harmonic at a time but never zero it*.

**A chiral shell contributes parity-odd terms to those sums.** Every shell CPP currently has contributes
only parity-even ones. A parity-odd term in the vacuum dispersion is **optical activity of the vacuum** —
an observable, not a parameter.

If the chirality strength sets its size, it is calibratable against one measurement and predictive
thereafter, and 4042's free magnitude acquires a consequence.

**That is the test of whether this reframe is explanatory or merely consistent.** It is **not computed** —
SR-1's machinery exists and this shell does not yet sit in it. It is the next piece of work and the one
that would settle the question the founder actually asked.

No panel. No verdict moved. FI-C-9 = V3 stands.
