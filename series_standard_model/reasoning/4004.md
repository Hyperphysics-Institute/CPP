## What the lift actually got, and where it stopped

0813 computed **χ_η = 0.87–1.01** — finite and positive, hence μ² > 0 and η = 0 stable. 0904 then made
a correction worth more than the number: 0813 had glossed this as chirality being *emergent*, and it is
the **opposite**. μ² > 0 is the **unbroken** branch. The engine is handedness-*neutral*, so it does not
generate chirality; FI-C-9 stays primitive, **V3 is confirmed**, and it is **V1-by-condensation** that
this forecloses. An inverted label on a correct computation, caught by the other lane.

And then 0904 §3 and 0905, which are the part that matters: that finiteness follows **near-tautologically
from a product (ZRP-template) base that was assumed**, and 0814 found the real Mechanism-A NESS **departs
from it, skewed at O(δ)**. 0905 is careful in a way I want to preserve: *departs from product is not the
same as critical*. The recomputed χ could be finite-but-non-product, or could reveal correlations. Nobody
knows, because nobody has run it. **The live item is a recompute, not a lift.**

## The PD-007 call, which turned out not to be a call

1100 named two branches: (i) an occupation/many-walker generator, (ii) a justified single-site reduction.
I expected to have to weigh them. I did not, because **(ii) is not unjustified — it is ill-posed.**

A susceptibility is a number-*fluctuation*. For a single walker the total occupancy is fixed at 1, so

    Σ_{v,w} ⟨n_v n_w⟩_c  =  Var(N_tot)  =  0     identically,

hence χ = 0 and m² = N/χ = ∞. That is not a bad approximation to the field susceptibility; it is
degenerate at zeroth order, and for a reason with nothing to do with the substrate. **There was never a
single-site reduction to find, so there was nothing to justify.** 1100 said the single walker "carries no
information about m²"; the sharper statement is that it cannot carry any, for any dynamics.

So the choice collapses to (i), and the working extension I adopt under PD-007, labelled **`[PCD-EXT]`**,
is the **occupation generator on a proper subvolume** — because a proper subvolume is exactly where the
number fluctuates: Var(n_S) = K p_S(1−p_S) > 0 for every 0 < p_S < 1. That is the definition 0905's
recompute needs in order to be well-posed at all.

## The diagnosis I tested and threw away

My first reading was much more satisfying: that −π_vπ_w is the signature of **hard-core exclusion**, and
therefore closed outright by **R-EXCL-RETIRED** (1 Sep) — a September ruling reaching back to kill a June
gap. It fit the D-2 shape perfectly, which should have been the warning.

I ran it before writing it. An **exclusion-free** multinomial gives Cov(n_v, n_w) = −K π_v π_w — same
sign, scaling with K, with multiple occupancy fully allowed. **The anticorrelation is the fixed total, not
exclusion.** R-EXCL-RETIRED has nothing to do with it.

Recorded in the script as a check rather than deleted, because the tidy wrong version is the one that
would have survived into three documents.
