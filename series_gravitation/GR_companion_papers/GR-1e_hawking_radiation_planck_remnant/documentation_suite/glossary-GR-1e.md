# Glossary — GR-1e

- **Geometric termination** — this paper's central proposition:
  evaporation ends because the semiclassical approximation becomes
  *geometrically undefined*, not because the temperature diverges.
- **N = r_S/l_P = 2M/m_P** — the lattice-cell count spanned by the
  Schwarzschild radius. The semiclassical treatment needs N ≫ 1; at
  M = m_P, N → 2.
- **The two-cell horizon** — at M = m_P, r_S = 2l_P, so the "horizon"
  is a boundary of width l_P separating two lattice cells from three.
  Hawking's mechanism requires a smooth thermal gradient across a
  near-horizon region; on the lattice, at this size, there is no such
  region.
- **T_Haw(m_P) = T_P/8π ≈ 0.040 T_P** — the Hawking temperature at
  termination: only 4% of Planck. The paper's cleanest point — the
  *thermal* constraint is not what binds; the *geometric* one is.
  (Note: the macro is `\THaw` after the Patch-3274 repair of a collision
  with LaTeX's built-in thorn character `\TH`.)
- **Planck remnant** — the endpoint: M_rem ~ m_P ≈ 2.18×10⁻⁸ kg, stable
  and unable to evaporate further.
- **The stability fixed point** — the remnant is *mechanically* stable,
  not merely kinematically stranded: gravitational SSV compression is
  exactly balanced by CP Exclusion repulsion at PSR_eff = l_P/2. No
  external pressure is required.
- **Evaporation time** — essentially unchanged from the standard result,
  since (m_P/M₀)³ ≪ 1 for any astrophysical hole: ~2.1×10⁶⁷ yr for a
  solar mass. The CPP modification lives entirely in the final Planck
  epoch.
- **Page time** — the point (≈ t_evap/2) after which unitary Hawking
  radiation must begin encoding information. Because CPP's modification
  is confined to the very end of evaporation, the early-time radiation
  is unchanged and the Page-time analysis is untouched.
- **Remnant information capacity** — of order k_B, from the CP
  configuration within the ~2l_P core. Far below the original
  Bekenstein–Hawking entropy S_BH = k_B A/4l_P², which is why the paper
  says the resolution must involve the whole radiation train, not the
  remnant alone.
