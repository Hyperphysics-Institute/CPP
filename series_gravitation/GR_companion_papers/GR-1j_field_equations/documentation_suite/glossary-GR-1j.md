# Glossary — GR-1j

- **Messenger census** — the per-Grid-Point tally of arriving DI-bits.
  Its conservation is the paper's engine: linearity, the kernel, the
  wave dynamics, the Birkhoff-type result, and the source current all
  descend from it.
- **Census linearity** — because emission is at fixed per-GP count and
  the tally is additive, superposed sources superpose in Δ|SSV|.
- **Homogeneous-Sea cancellation** — a uniform Sea contributes nothing
  net, so the dynamics closes on the *departure* field from homogeneity.
- **Shell-mean (one-hop) kernel** — each Moment's delivery is an average
  over the PSR shell. Its static fixed point is the mean-value property,
  which is Laplace's equation exactly — for any PSR profile.
- **Two-level relay closure** — u(t+τ) + u(t−τ) = 2·M_R·u(t). Forced by
  time-reversal invariance (A3′ full-Moment symmetry); the irreversible
  one-level alternative damps every mode and violates conservation, so
  it dead-ends.
- **Admissible class 𝒜** — 2[α·M_R + (1−α)I], α ∈ (0,1]: the whole
  one-hop-local family consistent with the closure. **Closure
  robustness** is the finding that every member yields the same
  continuum operator; only the coefficient moves.
- **T-1** — the ratified field equation: a variable-speed wave equation
  for the census potential, (1/c_*²)∂²_t(Δ|SSV|) − ∇²(Δ|SSV|) = source.
- **c_\*** — the emergent long-wave census speed, phase and group.
  **R-CSTAR-MAP** (ratified) fixes c ≡ R_vac/(√3·t_P): a units
  convention at the k standing, no long-wave observable content.
- **Log-lapse N** — N = ln√(−g_tt/c²) = −2·artanh(kΔ|SSV|/2). The
  measured-frame potential. □_g N = 0 in vacuum, exactly.
- **The equivalence theorem** — for generic v, □_g artanh(kv/2) is a
  pure algebraic factor times ∇²_flat v, with no derivative terms: the
  lattice equation and the measured-frame equation are ONE equation in
  two variables. Clock rates multiply, so the observer's potential is a
  logarithm; messenger counts add, so the substrate's is not.
- **F_true** — the correct compensator, O(u)·|∇v|², replacing the
  defective O(u²)·□ln term of the shipped GR-1c Proposition.
- **The corrigendum** — GR-1c V2.2. The defect was found by this
  derivation's own HALT check, diagnosed, approved 5–0 at CONV-027,
  founder-ratified, and enacted with the defective formula preserved.
- **T-2** — static uniqueness (exact) plus a *conditional* Birkhoff-type
  theorem: conditional because the bare equation admits monopole
  radiation; staticity is enforced by census conservation. Hypotheses:
  asymptotically-flat local class; no incoming radiation; C¹ regularity.
- **T-3** — the conserved census current (ρ, **J**): ρ is the
  compressed-DP SSV_abs excess density, **J** its CP-displacement flux,
  with ∂_tρ + ∇·**J** = 0 exact. A current, not a rank-2 tensor.
- **op:einstein** — the open frontier: whether the vector/tensor
  broadcast channels run through the same machinery yield full dynamic
  rank-2 Einstein structure, or a distinguishable alternative.
