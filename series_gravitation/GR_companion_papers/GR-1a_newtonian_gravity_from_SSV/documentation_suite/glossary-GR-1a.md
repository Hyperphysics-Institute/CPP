# Glossary — GR-1a

- **SSV shell broadcast** — the mechanism inherited from the Stiffness C
  companion: a Grid Point emits a fixed SSV quantum Q per Absolute
  Moment, distributed over the growing spherical shell at radius r, so
  ΔSSV ∝ Q/4πr² ∝ 1/r². Identical geometry for electromagnetism and
  gravitation; only the source differs.
- **The no-polarity argument** — the paper's central proposition. The
  eDP cloud contains equal numbers of + and − CPs, so their charge
  contributions cancel while their ZBW kinetic energies add. The
  resulting mass-energy SSV is a positive scalar with no polarity,
  across all four DP types equally.
- **Q_EM / Q_grav** — the per-tick SSV quanta. Q_EM = (e²/4πε₀)/(C l_P³)
  is sourced by charge polarity; Q_grav = (mc²/E_P)·Q_Planck is sourced
  by rest energy.
- **Q_Planck** — the SSV quantum emitted by one Planck-mass ZBW unit;
  the normalization through which G enters.
- **Stiffness C** — the Dipole Sea stiffness, C = α_geom·E_P/l_P³,
  inherited from the companion of the same name.
- **E_pol = mc²** — the compressive polarization energy stored in the
  eDP cloud during ZBW oscillation. The paper's key identification: the
  *same* quantity resists acceleration (inertial mass) and sources the
  gravitational SSV field (gravitational mass).
- **G = ħc/m_P² = l_P c²/m_P = c³t_P/ħ** — the boxed result. Exact and
  parameter-free, since m_P, l_P, t_P, ħ, and c are all fixed by the
  600-cell lattice and the Absolute Moment tick. Numerically
  6.674×10⁻¹¹ m³kg⁻¹s⁻².
- **The hierarchy ratio** — F_grav/F_EM = (m/m_P)²/(e/e_P)²: a pure
  ratio of Planck-unit suppressions. Gravity is weak because the
  electron mass is ~10²² times smaller than the Planck mass — a
  consequence of the ZBW assembly hierarchy, not a fine-tuning.
- **SSV_crit** — the stress scale at which the PSR formula saturates and
  the linear Newtonian approximation fails. Everything in this paper
  lives at ΔSSV ≪ SSV_crit; the companions live above it.
