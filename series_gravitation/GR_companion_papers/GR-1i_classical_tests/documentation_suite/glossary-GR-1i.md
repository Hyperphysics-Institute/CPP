# Glossary — GR-1i

- **Isotropic coordinates** — the form in which the arc's exact solution
  naturally appears; the spatial metric is conformally flat, so the two
  broadcast components separate cleanly: g_tt carries the scalar
  (|SSV|_abs) content, the conformal factor (1+ρ)⁴ carries the vector
  (**SSV**_net) content. GR-1j later derives *why* the solution takes
  this form (the lattice is flat).
- **Binet equation** — the orbit equation in u = 1/r used for both
  dynamical tests; the timelike form carries the ∝u² relativistic term,
  the null form the deflection.
- **The ∝u² correction** — the orbit-scale fingerprint of the
  *unexpanded* PSR response. Perihelion precession is the only one of
  the four tests sensitive beyond first order in ρ — the first
  observable that sees the PSR formula as a full constitutive law rather
  than a linearization.
- **Graded-index Sea** — the mechanism reading of light propagation:
  PSR shrinkage near the mass makes the Sea effectively denser, giving
  a refractive index n(r) ≈ 1 + 2GM/c²r. Deflection is refraction;
  Shapiro delay is the same slowing integrated along the path.
- **The factor of two** — half of the deflection comes from time
  curvature (scalar channel), half from spatial curvature (vector
  channel). A scalar-only substrate gives 0.875″ against the measured
  1.75″. The paper's sharpest discriminant, and it cuts against
  scalar-only *variants of CPP itself*, not only against Newton.
- **Achromatic bending** — n(r) is frequency-independent, so limb
  deflection carries no chromatic dispersion. Registered as an implicit
  falsifiable feature (unminted): chromatic dispersion at the limb would
  falsify the mechanism as formulated.
- **PPN β = γ = 1 identically** — structural, not numerical: Cassini
  compliance follows from the metric being exactly Schwarzschild, so the
  leading-log Shapiro figure is a coarse consistency check, not a
  precision γ test.
- **Reproduces vs shares** — the frozen claim-discipline distinction:
  CPP *reproduces* GR's classical tests; it does not *share* GR's
  theoretical basis. Agreement is a derived consequence, not a
  reformulation.
- **Implementation cross-check** — the numeric Binet integration
  agreeing with the closed forms tests the *implementation*; both routes
  instantiate the same Schwarzschild geodesics, so the agreement is not
  independent physical evidence.
- **φ-accumulation drift / crossing overshoot** — the two documented
  numerical traps, each capable of silently corrupting a result at a
  level large compared to the signal.
