# Glossary — GR-1g

- **The three SSV sources** — the paper's organizing structure. Scalar
  compressive SSV from mass M (GR-1c); azimuthal vector SSV from angular
  momentum J (GR-1f); **radial vector SSV from charge Q** (inherited
  from the Stiffness C companion). All three source the same spacetime
  simultaneously.
- **Δ_KN = r² − 2Mr + a² + Q²** — the Kerr–Newman structure function.
  The charge term enters by adding the Coulomb SSV contribution to the
  Kerr Δ; in geometric units Q² = k_e Q_SI² G/c⁴.
- **Kerr–Newman bound M² ≥ a² + Q²** — derived from SSV subluminality at
  the outer horizon, generalizing GR-1f's Kerr bound to the
  three-component case. As there, extremality is a causality limit
  rather than a censorship conjecture.
- **Reissner–Nordström** — the a = 0 limit, recovered as a corollary:
  a charged, non-rotating hole.
- **Σ = r² + a²cos²θ** — the Boyer–Lindquist structure function. As in
  GR-1f, obtaining Σ and Δ_KN *at all orders* from the nonlinear PSR
  formula with the total three-component SSV magnitude is `op:allorders`,
  open.
- **Planck ring core** — the Kerr–Newman analogue of GR-1c's Planck
  core. At the would-be ring singularity (r = 0, θ = π/2), Σ → 0 and the
  classical metric diverges; the bound PSR_eff ≥ l_P/2 saturates the
  lattice at Planck density first, replacing the ring singularity with a
  Planck-density ring.
- **Charge neutralisation** — the reason the remnant chain usually
  reduces to Kerr → Schwarzschild → Planck remnant: for most
  astrophysical holes charge is neutralised rapidly, so the charged
  branch is a limiting case rather than the generic history.
- **Φ₊** — the electrostatic potential at the outer horizon; it appears
  in the Kerr–Newman superradiance threshold ω < mΩ₊ + qΦ₊ (GR-1h).
