# Patch 3634 — reasoning fragment (verbatim, Tier 4)

Thomas held the round, so I took the next item on the handover's list
that needs no panel, and it turned out to be the one with the bigger
surprise.

The corpus had decided, in the CONV-041 adjudication, that neutron
stars do not saturate because a uniform body's register reaches the
cap only at M/R ≈ 0.44, the Buchdahl bound. I had written that. It was
wrong twice. The 0.44 was the isotropic ratio M/R̄, not an areal
compactness — mapped outward through the exterior it is 0.30. And it
was Newtonian in a place where the corpus has an exact relativistic
rule: the register is the lapse. That rule is ratified and it fixes
the exterior identically; inside a star it says saturation is central
lapse one half, full stop. For a uniform-density star that is C = 5/18
= 0.278; Buchdahl is where the central lapse hits zero, twice as far.

Then TOV. Every polytrope I ran — Γ = 2, 2.5, 3 — crosses central
lapse ½ on the stable branch, before the maximum mass, at compactness
0.20 to 0.24. The heaviest measured pulsars sit at 0.25 with central
redshifts of order one. So the sentence "neutron stars do not
saturate" fails exactly for the stars we can weigh best. There is a
class the corpus did not have: a saturated core under an unsaturated
envelope, and it is populated.

I am not sure yet what the theory says happens to matter there. 3375
describes the over-demanded interior for the R-core — register pinned,
clocks at ½, no further response to count — but that was a fully
collapsed object. A pinned core inside a star that is still supporting
itself is a different question, and whether the pinned register
changes the support or only the clocks is a picture, so I am asking
Thomas for it. If the register stops responding to added count, the
lattice-read weight of the core stops growing and the maximum mass
moves — that would be a test against existing data, which is the kind
of thing this arc should be producing.

The GR-2 paragraph that says neutron stars do not saturate is exposed
and will go with V2.3 when the round runs; nothing enacted today.
