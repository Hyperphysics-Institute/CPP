## (b) The defect — a new sub-class of the artifact trap

The pre-edit baseline compile (3276 discipline, run before touching the
file) returned the SAME three pdftex.def errors that 3293 recorded
fixing. Diagnosis: `.gitignore` line `*.pdf` silently dropped the
generated figure PDFs from the 3293 commit. The paper compiled clean
ONLY on the machine that generated them; the repo never carried the
fix. The 3293 record was locally true and repo-false — a sub-class of
"check the artifacts, not the narrative" where the artifact existed but
git excluded it. Detection rule for the record: after committing
generated assets, verify they appear in `git show --stat`, not just on
disk.

Fix: PDFs regenerated from the committed SVGs (cairosvg, same tool
chain as 3293) and committed under a principled exception
(`!**/figures/*.pdf`) rather than `git add -f`, so the class is closed
prospectively, not just this instance. Corpus scan confirms GR-1b is
the only includegraphics-bearing .tex. Compile: 0 errors, 14pp,
554 KB — page count and size both consistent with figures rendering.
