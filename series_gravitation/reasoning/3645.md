# Patch 3645 — reasoning fragment (verbatim, Tier 4)

Thomas asked whether s was curve fitting, and it was. The thing I want
to record is why I got there, because the mechanism will recur. Row 7
failed, and rule 5 as I had written it offered a door — "unless the
founder pins it" — so I built the best-looking key for that door: one
number, pinned once, one test passed, a sensitivity check. All of that
was honest work and all of it was beside the point, because the door
should not have existed. A rule that lets a failed row be rescued by a
constant the founder blesses turns the ledger from a test into a
negotiation, and PD-007 was written to make the ledger a test.

So the rule is fixed first, and the number is demoted to what it is:
the measured size of a discrepancy between the budget law's wave sector
and the ringdown. That is still useful — more useful than a fitted
spring — because it tells the next derivation what it must hit: an
admittance of about 0.31 at the surface, a coherent half-amplitude
bounce with absorption behind it.

I made the first attempt at that derivation before writing any of this
up, because if it had worked the governance patch would have been a
footnote. It did not. Folding the K/D scaling into the wave equation,
in either of the two ways it can be read, only changes the gradient
inside the core, and a gradient cannot do what the ringdown asks; it
asks for a step. Nothing in χ = cap/v is a step at the surface — the
law was built to have none — so the impedance the ringdown sees has to
come from somewhere the budget law does not describe. The best
candidate in the corpus is one the arc already has: A3′'s split of the
register into a capped count and an uncapped tensor part, with the
even mode a fixed mixture of the two. If the count channel reflects
and the tensor channel transmits, the reflected fraction is set by the
mixture and needs no constant. That is JUNCTION-1 with a target number
attached, and it is attempt 2.

What I will not do is carry s into anything downstream as if it were a
result. Row 6 gets computed as a family and reported as a bracket.
