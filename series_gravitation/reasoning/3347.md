# Patch 3347 — reasoning fragment (verbatim, Tier 4)

The corpus-wide quantifier audit CONV-035 owed. I wanted to run it
rather than be handed its results by a sixth round, and the result
justifies the preference: it found a third instance of the class, in
GR-2, which I shipped six versions of today.

METHOD NOTE WORTH KEEPING. Pass 1 flagged 169 sentences and was
useless as a verdict list - because it caught analytic universals,
where "for every admissible X" is licensed BY PROOF. That distinction
IS the class definition: the defect is not a universal word, it is a
universal whose warrant is a COMPUTATION narrower than the sentence.
Pass 2 encoded that and returned 18, all readable in one sitting.
Getting from 169 to 18 was not tuning a threshold to a comfortable
number; it was noticing that pass 1 had the wrong theory of the
defect.

THE FIND. GR-2 section 2 says "every number is reproduced by the
paper's verify script." It is not. The ~5% amplitude was inherited
from GR-1d and never in 3329 - false since V1.0 - and then I made it
worse three times today, adding ell_crit, the 0.122 slope, the
165-mode domain, 236 Hz, the four eikonal tops, and the delta_w
envelope, every one of which is verified by 3333/3334/3339 and none
by "the paper's verify script." I re-read that paper four times today
and never re-read that sentence, because it was true when I wrote it.

That is the generalization worth more than the fix: VERIFICATION
CLAIMS ROT. All three instances of the class, plus the stale "this
paper is V0" limits line I caught at 3338, are sentences that were
true when written and were falsified by later work IN THE SAME FILE.
I noticed the V0 rot at 3338, called it "the status-rot class the
corpus has caught twice before," and then did not generalize from it
to the verification sentence four paragraphs away. Registering the
standing practice now: any sentence asserting what a script covers is
re-read at every version bump of that file, and asserted in code
where practical.

THE BEST NEGATIVE RESULT. GR-1i makes the SAME claim in the SAME
words - "every number is machine-verified... 8/8 PASS" - and it is
TRUE; the eight checks do cover every table entry. Identical sentence
shape, opposite verdicts, and the only way to tell was opening the
script. That is the whole audit in one comparison: the shape is not
the defect, the mismatch is. It also means a text-only reviewer could
not have caught either one.

WHAT I DID NOT DO. I did not soften GR-1c's "Every result in the CPP
series traces to the PCD cycle" into a third paper patch tonight. It
is a programmatic claim, not a computational one, so it is outside the
audited class - but it IS a universal over lanes I have not audited,
so it is registered as a queued edit rather than quietly left. And I
did not claim the audit clears the corpus: 4.3's ten CLEAN verdicts
are my reading alone, and the record says so and offers them for
panel audit.

Scale, for calibration: 1,753 sentences, 271 universal claims, 18
candidates, 1 defect. The class is real and recurrent - three
instances, all found by looking, none by five review rounds and
twenty-five seat returns - but it is NOT endemic. The lane's
universals are overwhelmingly analytic or properly scoped. The
failures cluster in exactly one place: where prose asserts what a
script covers.

seeing a "Patch 3346: LANE-ISOLATION PROTOCOL" commit in my clone.

  4/5 with the adjudication at PARTIAL-FINAL v1.0, GR-2 at V1.2, and
  no ell_crit +/-1 in predictions.md.

I could not have detected this by looking at my own clone. My clone

FINAL ADDENDUM — THE INSTRUMENT LIED QUIETLY, AND ONLY A SECOND
WORKING DIRECTORY EXPOSED IT.

series_gravitation/code/ instead of the repo root. It reported

This is the worst failure mode a verification instrument has. A
crash is honest. A clean bill of health over an empty corpus is a
lie that passes every check, and it is precisely the shape of the
defect this very patch was written to hunt: an all-clear whose
domain is narrower than it appears - here, empty.

now agree at 1,753 / 271 / 18.

Three defect instances went into this patch's record. This is a
