## The four falsifiers

**F1 — PRED-O-35 — Polarization content (pure tensor).**
CPP predicts first-order gravitational-wave polarization is *pure tensor* — Eardley class N₂, the
two helicity-±2 (+, ×) modes only. No first-order breathing (scalar), longitudinal, or vector mode.
*Falsifier:* any confirmed first-order breathing/longitudinal/vector GW polarization. *Backed by*
THEO-SR-EIN-3 (cancellation) + THEO-SR-EIN-4 (operational energy). *Status:* consistent with current
multi-detector polarization tests, which favour tensor over scalar/vector.

**F2 — PRED-O-36 — Propagation speed (exactly c).**
The quadrupole channel propagates by the identical icosahedral shell-sum that carries light, so
GW speed = c exactly. *Status:* GW170817 gives |c_GW/c − 1| ≲ 10⁻¹⁵ — passed by construction.
*Falsifier:* any confirmed deviation of GW speed from c.

**F3 — PRED-O-37 — Multiplet integrity (no fine-structure); lattice discriminant.**
The five-fold l=2 multiplet is protected exactly by the icosahedral rotation group (irrep H), so
there is no polarization fine-structure or splitting-induced birefringence. This doubles as a
*lattice discriminant*: a cubic substrate would split the multiplet 2+3 (E ⊕ T₂), the icosahedral
600-cell does not. *Falsifier:* any observed polarization fine-structure/splitting — which would
both falsify A3′ as stated and select against the icosahedral substrate. *Backed by* THEO-SR-EIN-1.

**F4 — PRED-O-38 — Dispersion (flat carriage).**
Flat (absolute-frame) carriage of the packet predicts no helicity-dependent vacuum dispersion beyond
the flat-carriage ceiling θ < 10⁻⁴⁶–10⁻⁵¹ (the empirical bound on a substrate twist; Patch 1119).
*Falsifier:* a confirmed helicity-dependent vacuum dispersion above that ceiling.

## Distance to data

F1 (polarization) is the near-term discriminator as the detector network grows and polarization
constraints tighten. F3 (the lattice discriminant) is the most distinctive long-horizon signature —
a 2+3 fine-splitting would be a smoking gun *against* an icosahedral substrate. F4's ceiling is so
far below current sensitivity that it functions as an in-principle, not near-term, test.
