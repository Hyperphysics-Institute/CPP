## Why the no-go is real but doesn't bite CPP
Two independent facts converged:
1. Any periodic lattice (any hopping range) has a bounded, BZ-periodic dispersion symbol — a trig
   polynomial — which can't equal the unbounded c|k| or be exactly isotropic. Finite shells suppress
   the icosahedral anisotropy tower (l=6,10,15,...) one harmonic at a time, never all. So exact W1 is
   impossible for a periodic substrate. (Numerically clean: phase speed collapses 0.998->0.797;
   single-shell q^4 -> tuned-2-shell x11 smaller but nonzero.)
2. BUT the CPP substrate is NOT periodic. SR-1's canonical "nested 600-cell hierarchy" is
   phi-self-similar at every level (R/a=phi) — that IS an icosahedral quasicrystal (aperiodic, no BZ).
   And independently, a 600-cell admits no periodic Euclidean 4-tessellation at all (Coxeter: only
   {4,3,3,4}/{3,3,4,3}/{3,4,3,3}; {3,3,5} tiles S^3 / hyperbolic, not E^4). So the substrate is
   non-periodic by necessity — in the no-go-EVADING class by construction.

The honest synthesis: the periodic no-go is real and would force W2 — but it is MOOT for CPP, whose
substrate is aperiodic. Aperiodicity is the known route (causal sets via randomness; quasicrystals via
deterministic self-similarity) by which a discrete structure carries exact (statistical) Lorentz. So W1
is not killed; it is pinned to the quasicrystal-Lorentz question.
