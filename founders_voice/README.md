# founders_voice/

First-person mechanism records and conceptual notes in Thomas Lee Abshier's own voice — the billiard-ball-and-cue-stick accounts that sit *behind* the formal papers. Parallel to `opus_voice/`.

These are **pictures, not proofs**: physical mechanisms stated mechanically and consistent with the corpus and the experiments, each carrying an honest status note on what remains to be derived. They record the founder's mechanical intent so the formal derivations have a target to aim at.
