3. **Nuclear cascade figure.** *Decision:* state RMS < 1% (8-set 0.91%), the source-grounded SS-7 v1.2 figure. *Alternative:* the staging-doc "< 1.5%." *Rejected because:* the source supports the tighter, stronger figure.
4. **SS-3 uniqueness scope.** *Decision:* "unique within the operator representation," per SS-3's own conditional restatement. *Alternative:* "unique from the cage." *Rejected because:* over-claims SS-3's actual scope.
