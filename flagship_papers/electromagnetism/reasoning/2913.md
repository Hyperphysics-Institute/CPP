before any Stage-2 machinery exists to produce a number, with the
static-Sea target (one fifth, exactly) written next to them so that
neither I nor a successor can later blur what cancellation is measured
against. The one methodological novelty - that c_hyb depends only on

collapse test exists to catch the one way it fails silently
(nonlinearity in beta masquerading as shape).
