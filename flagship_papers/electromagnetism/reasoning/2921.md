# REASONING FRAGMENT — PATCH 2921 (verbatim worker reasoning, Tier 4)

1. Both corrections restore exactness the physics already owns;
   neither introduces a tunable. Interpolation has no parameter; odd
   projection is a projection. That is the line between repairing an
   instrument and steering it.
2. The new abort-grade assert (1e-15) is deliberately harsher than
   2919's 1e-12: with interpolation the zero is exact by
   construction, so any violation is a coding error, and aborting is
   correct. The 2919 assert failed partly because it tested a noisy
   estimator against an exact property -- the 3b design separates
   the exact claim (evaluator parity, abort-grade) from the noisy
   one (even residue of p0, reported as a gauge).
3. s4 exists because I can see the round-3 numbers (c_tot ~ 16 under
   the defective evaluator) and cannot unsee them. Freezing the
   interpretation of a large-c outcome BEFORE the clean measurement
   prevents the worker from later choosing whichever reading of a
   large c is convenient. The perturbative form dying on this beta
   range is a real possibility with real consequences for how B1
   confronts Newton I -- if it happens, it gets its own
   non-perturbative prereg, not a rhetorical patch.
