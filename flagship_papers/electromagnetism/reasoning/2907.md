# Reasoning fragment — Patch 2907 (round-3 prereg: kill the systematic by construction)

**STATUS: contemporaneous. Prereg at
`sketches/mobile_sea_round3_prereg.md`; driver at
`code/2907_round3_driver.py`. Committed before any round-3 leg.**

Round 2's lesson was that I had been buying statistics while the bill
was systematics. Round 3 spends nothing on statistics it does not first
secure by symmetry: transits centred on the one point the truncated
domain is honest about, a second grid class to keep the washboard
averaged, and jitter that is mirrored so that randomness itself cannot
break reflection symmetry. The elegant consequence, which the prereg
turns into a hard gate rather than a hope: at beta zero the whole
evolution is symmetric, so every floor leg - mobile included - must
read floating-point zero, and if any reads above 1e-12 the round aborts
before a single moving leg is looked at. A floor that must be zero
makes the old five-times-floor criterion vacuous, so the significance
requirement moves to three sigma of the ensemble's own scatter, frozen
now, for the stated reason, before I know what the scatter is.

I also wrote the expectation caveat into the prereg itself this time:
cancellation, declared a fifth time, has gone three rounds without
support and rests on one argument from Patch 2900. If round 3 comes
back drag-signed or null, the record should show I said so where the
bands live, not only in a reasoning file.
