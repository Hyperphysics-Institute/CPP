# Reasoning fragment — Patch 2905 (round-2 spec was geometrically infeasible; amended before execution)

**STATUS: contemporaneous. Amendment at
`sketches/mobile_sea_round2_amendment.md`.**

I froze a spec yesterday that cannot run: quadrupled windows mean
quadrupled transits, and at beta 0.2 the source would coast 58 units
through a Sea that is 30 units long. I never multiplied beta by the
window before committing it. That is the same failure class as the 2886
configuration errors - freezing procedure without checking that the
procedure is physically executable - and the only mitigation I can claim
is that this one was caught by arithmetic before a single Moment ran,
not by an inconclusive verdict after.

The amendment keeps everything that carries epistemic weight - the
observable, the bands, the floor construction, the null-interpretation
note - and changes only how the statistics are gathered: four transits
at quarter-staggered grid phases instead of one long transit. Same total
Moments, so same raw power, and the quarter-phases kill the washboard
fundamental exactly rather than merely averaging it. Honestly, this is
the design I should have written the first time; the record of round 1
even listed phase-averaging as resolution 2 and I reached past it for
the blunt instrument of longer windows.

The compiled-kernel change is declared with a frozen gate because
"faster" must never quietly become "different": identical float64
bisection, agreement to 1e-10 on the measured quantity, standard
validations passing, evidence committed. If the kernel cannot meet the
gate, the round runs slow on the reference path.

Committing this before any round-2 leg exists, separately from the
execution record to come, so the order is in the history and not in my
narration.
