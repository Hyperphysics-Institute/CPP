## The bug fixed

The §10 roadmap table (`tab:consist`) used `%%TODO` as the literal *status* cell value in nine member rows: `... & %%TODO \\`. Because `%` is the LaTeX comment character, each such cell commented out its own row terminator `\\`, collapsing rows and throwing "Extra alignment tab has been changed to \cr" (fatal, no PDF). Fix: the nine in-table `%%TODO` status cells → `to build` (real rendered text, which the status column needs anyway). The standalone `%%TODO:` comment lines elsewhere in the source are correct LaTeX comments and were left as-is — they mark scaffolded content for later fill-in patches.
