## Row-sum verifications (each B-row must sum to S_edge(O_i))

The single identity that closes every row is `1/phi = phi - 1`, equivalently
`1/phi^2 = 2 - phi`. Worked by hand at patch-time:

- O_1: -1 - 5/2 + 5/(2phi) + phi/2.  Use 5/(2phi) = 5(phi-1)/2:
       = -7/2 + (5phi-5+phi)/2 = (6phi-12)/2 = 3phi-6 = 3(phi-2).
       And -3/phi^2 = -3(2-phi) = 3phi-6.  MATCH.
- O_2: -1/2 + (1-2phi)/2 + (2phi-1)/2 + 1/2.  The two middle terms are exact
       negatives; the outer two cancel. = 0 EXACTLY (phi-independent). This is
       the seed of A5-F3.
- O_3: 1/(2phi) + (2phi-1)/2 + (3phi-4)/2 + 0.  Middle two: (5phi-5)/2 =
       5(phi-1)/2 = 5/(2phi). So total = 6/(2phi) = 3/phi.  MATCH.
- O_4: phi/2 + 5/2 + 0 - 1/(2phi).  Use 1/(2phi)=(phi-1)/2:
       = [(phi+5) - (phi-1)]/2 = 6/2 = 3.  MATCH.

All four reproduced symbolically in scripts/0605.py.

## Inline Lemma: the cross-shell additive constant +phi^2/2

This was the one genuinely new piece of derivation in the patch (everything
else inherited). The cross-shell (S_1 -> S_3) edge projection onto n_edge:

    hat_e_{u->v'} . n_edge = phi^2 (v'.V_1 - u.V_1) + phi^2/2

The +phi^2/2 absorbs the host-axis radial asymmetry
    u.v_host - v'.v_host = phi/2 - 1/(2phi) = phi/2 - (phi-1)/2 = 1/2.

KEY REASONING (why phi^2/2 here, not phi/2 as in Patch 0604):
Patch 0604's generic cross-shell formula carried an additive +phi/2. Here the
constant is phi^2/2 — an extra factor of phi. The extra phi comes from the
edge-aligned projection: n_edge projects onto the relevant 5-fold sector as
phi*V_1 (Patch 0600 Lemma 2.2), so the radial-asymmetry term 1/2 gets scaled
by phi^2 (one phi from the chord normalization, one from the n_edge
projection) rather than by phi. I checked this against Patch 0604's X-F1
structural identity to make sure I wasn't double-counting a phi — the two are
consistent because they project onto different directions (generic vertex
projection in 0604 vs n_edge here).

The lemma then yields the B.4 orbit values {+phi/2, +1/2, 0, -1/(2phi)},
generalizing Patch 0591's *uniform* -phi/2 at vertex-aligned. The breaking of
uniformity (incl. the exact zero at O_3) is the edge-aligned signature.

## B.2 sign-flip note (why both coefficients end up positive)

At vertex-aligned B_2 == 0 identically (Patch 0591 §4.3). At edge-aligned B_2
turns on, with dominant entries -5/2 (O_1) and +5/2 (O_4). This is the
structural reason alpha_2 flips from negative (vertex) to positive (edge). I
flagged this as the mechanism in A5-F2 and as the quantitative closure of the
Patch 0599 §5 B.2 observation (A5-F5). I did NOT fully trace the projected
sum to a closed positivity proof — that is honestly a Layer-4 gap; the patch
asserts the mechanism and shows the dominant terms, no more.

## Workflow protocol used (preserve — this is the verification discipline)

Before shipping any .patch I now dry-run it in a throwaay git repo:
    cd /tmp && rm -rf t && mkdir t && cd t && git init -b main &&
    git commit --allow-empty -m init && git am <patch> &&
    diff <applied-file> <source-file>   # must be identical
This caught nothing on 0605 but is cheap insurance against a malformed hunk
header (line count) silently corrupting the apply. Always check round-trip
identity + that \begin{document}/\end{document} survived.
